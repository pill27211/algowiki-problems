#1061

소수와 쿼리 (Small)

난이도 3 ⏱ 2.000s 🧠 128 MB
수학 정수론 소수 판정 쿼리형 문제

문제

다음과 같은 쿼리를 처리하는 프로그램을 작성해보자.

  • $l$ $r$ : $[l, r]$에 존재하는 소수의 개수를 출력한다.

입력

첫째 줄에 쿼리의 개수 $Q$개 주어진다. $(1 ≤ Q ≤ 1,000)$

둘째 줄부터 $Q$개의 줄에 걸쳐 $l, r$이 공백으로 구분되어 주어진다. $(1 ≤ l ≤ r ≤ 1,000)$

출력

쿼리가 주어질 때마다 그에 맞는 답을 차례대로 출력한다.

예제

예제 입력
3

3 8

5 15

11 11
예제 출력
3

4

1

힌트

문제 해결에 어려움이 있다면 소수 판정 위키를 참고하자.
