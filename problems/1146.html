#1146

못해도 평균은 돼야지

난이도 2 ⏱ 1.000s 🧠 512 MB
구현 수학 사칙연산

문제

$n$명의 학생이 받은 점수가 주어진다. 이들의 점수 평균을 구하고, 평균을 넘지 못한 사람, 평균인 사람, 평균을 넘은 사람의 수를 모두 구해보자.

점수 평균은 다음으로 정의한다.

  • $n$명의 학생이 받은 점수 $p_1, p_2, ... , p_n$에 대해, $⌈\frac{\sum\limits_{i=1}^n p_i}{n}⌉$

입력

첫째 줄에 테스트 케이스의 수 $T$가 주어진다. $(1 ≤ T ≤ 1,000)$

둘째 줄부터 $T$개의 테스트 케이스가 주어진다. 각 테스트 케이스에서는 먼저 학생의 수를 의미하는 $n$이 주어지고, 그 다음 줄에 $p_1, p_2, ... , p_n$이 공백으로 구분되어 주어진다. $(1 ≤ n, p_i ≤ 100)$

출력

각 테스트 케이스마다 점수 평균, 평균을 넘지 못한 사람, 평균인 사람, 평균을 넘은 사람의 수를 공백으로 구분하여 출력한다.

예제

예제 입력
3

5

1 2 3 4 5

3

3 3 3

2

2 4
예제 출력
3 2 1 2

3 0 3 0

3 1 0 1

테스트 케이스마다 학생들의 점수의 총 합을 구하자. 나아가 그 합을 다시 학생의 수로 나누어 점수 평균을 구하자. 이때, 그 값이 정수가 아닐 경우 $ceil($올림$)$ 처리 해야 함을 유의해야 한다.
이제 평균을 넘지 못한 사람, 평균인 사람, 평균을 넘은 사람의 수를 기록할 변수 $3$개를 두어 문제를 해결할 수 있다. 

cnt1, cnt2, cnt3

for i    ← 1 to n

    if score[i] < avg

        cnt1++

    elif score[i] == avg

        cnt2++

    else

        cnt3++
