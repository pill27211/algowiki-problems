#1007

구구단

난이도 1 ⏱ 1.000s 🧠 128 MB
수학 구현

문제

$N$이 주어진다. 구구단 $N$단을 출력해보자.

입력

첫째 줄에 양의 정수 $N$이 주어진다.$(1 ≤ N ≤ 9)$

출력

예제의 출력 형식과 같게 구구단 $N$단을 출력한다.

예제

예제 입력
3
예제 출력
3 * 1 = 3 

3 * 2 = 6 

3 * 3 = 9 

3 * 4 = 12 

3 * 5 = 15 

3 * 6 = 18 

3 * 7 = 21 

3 * 8 = 24 

3 * 9 = 27

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
반복문의 사용과, 출력 형식의 요구를 정확히 수행할 수 있는지를 묻는 문제이다.
  • $1$부터 $9$까지 하나씩 증가하는 변수 $i$를 두자.
  • 출력 형식 $a * b = c$ 에서, $a = N$, $b = i$, $c = N * i$가 된다.
  • 각 $i$마다 위를 바탕으로 출력문을 작성해주자.
  • 수, 기호 사이가 공백으로 잘 구분되어 있는지, 각 출력이 개행으로 잘 구분되어 있는지에 유의하자.
