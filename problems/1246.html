간단한 문제 1

난이도 7 ⏱ 1.000s 🧠 512 MB
수학 정수론

문제

간단한 문제를 하나 풀어보자. 정수 $n$이 주어질 때, 다음 값을 구하면 된다.

  • $\sum\limits_{i=1}^n {⌊\frac{n}{i}⌋}$

입력

첫째 줄에 정수 $n$이 주어진다. $(1 ≤ n ≤ 10^{12})$

출력

첫째 줄에 $\sum\limits_{i=1}^n ⌊\frac{n}{i}⌋$의 값을 출력한다.

예제

예제 입력
10
예제 출력
27
