#1070

두 배열

난이도 3 ⏱ 2.000s 🧠 512 MB
정렬 투 포인터

문제

모든 요소가 정수인 길이 $n$의 배열 $a = [a_1, a_2, ... , a_n]$과 $b = [b_1, b_2, ... , b_n]$이 주어진다. 이 두 배열을 합친 결과를 출력하자.

단, 합친 결과를 $[c_1, c_2, ... , c_{2n}]$이라 할 때 $c_1 ≤ c_2 ≤ ... ≤ c_{2n}$ 을 만족해야 한다.

입력

첫째 줄에 배열의 길이 $n$이 주어진다. $(1 ≤ n ≤ 100,000)$

둘째 줄에 $a_1, a_2, ... , a_n$이 공백으로 구분되어 주어진다. $(-10^9 ≤ a_i ≤ 10^9)$

셋째 줄에 $b_1, b_2, ... , b_n$이 공백으로 구분되어 주어진다. $(-10^9 ≤ b_i ≤ 10^9)$

출력

첫째 줄에 $c_1, c_2, ... , c_{2n}$을 공백으로 구분하여 출력한다.

예제

예제 입력
3

-1 1 3

-3 -1 2
예제 출력
-3 -1 -1 1 2 3

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.

$a$를 순회하는 포인터 $i$와 $b$를 순회하는 포인터 $j$를 각각 두고, $a_i$와 $b_j$의 비교 결과에 따라 오름차순으로 정리할 수 있다.

이 경우 $i$나 $j$ 중 어느 하나가 배열의 끝에 도달하게 될테고, 남은 $a$나 $b$를 새로운 배열 뒤에 붙여주면 된다.

또 다른 방법으로, 그냥 $a$와 $b$를 이어붙인 배열에 대해 정렬을 진행해도 된다.

첫 번째 방법의 경우 $O(n)$, 두 번째 방법의 경우 $O(nlogn)$의 시간복잡도를 갖는다.
