#1232

트리 위 거리의 합의 합

난이도 9 ⏱ 1.000s 🧠 512 MB
다이나믹 프로그래밍 트리 트리 위 다이나믹 프로그래밍

문제

$1, 2, ... , n$의 번호가 고유하게 매겨진 $n$개의 정점이 트리 구조를 이룬다. 모든 간선의 길이가 $1$로 동일할 때, 다음 값을 구하여라.

  • $\sum\limits_{i=1}^n \sum\limits_{j=1}^n d(i, j)$
    • $d(i, j)$ : $i$번 정점에서 $j$번 정점에 이르는 최단 거리

입력

첫째 줄에 정점의 개수를 의미하는 정수 $n$이 주어진다. $(1 ≤ n ≤ 100,000)$

둘째 줄부터 $n-1$개의 줄에 걸쳐 간선 하나가 연결하는 두 정점의 번호 $u, v$가 공백으로 구분되어 주어진다. $(1 ≤ u, v ≤ n; u ≠ v)$

출력

첫째 줄에 $\sum\limits_{i=1}^n \sum\limits_{j=1}^n d(i, j)$의 값을 출력한다.

예제

예제 입력
6

1 2

1 3

2 4

2 5

3 6
예제 출력
64

매번 일일이 그래프 탐색을 진행하기엔 당연히 무리가 있다. 두 부분 문제로 쪼개어 풀어보자.
1. 서브 트리 내에서의 답
구해야 하는 값의 범위를 서브 트리로 줄여보면 어떨까? 즉, 다음을 계산하자는 것이다. 

sub[i] : 정점 i에서 i를 루트로 하는 서브 트리 내 모든 정점으로 향하는 최단 거리의 합.
위를 계산하기 위해선 서브 트리의 크기 조사가 절대적으로 필요하다. 

sz[i] : 정점 i를 루트로 하는 서브 트리의 크기
트리 구조임을 생각하면, 정점 $now$와 $now$의 자식 $nxt1, nxt2, nxt3, ...$에 대해 다음의 관계식이 성립한다. 

sub[now] = (sub[nxt1] + sz[nxt1]) + (sub[nxt2] + sz[nxt2]) + (sub[nxt3] + sz[nxt3]) + ...
2. 그 외 모든 정점으로의 답
각 정점마다 서브 트리 단에서의 답은 모두 계산하였다. 이제 정점마다 해당 정점의 서브 트리 외에 다른 모든 정점으로의 답을 계산해야 한다.
이는 앞서 전처리 한 $sub, sz$를 잘 활용하여 재귀적인 관계식을 정리할 수 있다. 다음을 참고하자. 

ans[i] : 정점 i에서 다른 모든 정점으로 향하는 최단 거리의 합



dfs(now, val)                   ← 현재 정점, 루트로부터 이어져 오는 누적값

{

    ans[i] = sub[i] + val       ← 우선 서브 트리 내에서의 답과 누적값을 취한다.

    for nxt                     ← now의 자식 노드 순회

        op1 = n - sz[nxt]

        op2 = sub[now] - sub[nxt] - sz[nxt]

        dfs(nxt, val + op1 + op2)

}



op1 : now와 nxt를 잇는 간선이 이용되는 횟수

op2 : now에서 nxt가 아닌 다른 자식 노드로 향하는 최단 거리의 합
