#1181

순서쌍의 개수

난이도 3 ⏱ 1.000s 🧠 512 MB
수학 애드 혹

문제

폐구간 $[1, N]$에서 다음 등식을 만족시키는 정수 순서쌍 $(A, B)$의 개수를 구하여라.

  • $⌊\frac{A+B}{2}⌋$ $=$ $(A$ $\&$ $B)$ $+$ $((A$ $⊕$ $B)$ $>>$ $1)$  $(1 ≤ A ≤ B ≤ N)$

입력

첫째 줄에 구간의 끝을 의미하는 정수 $N$이 주어진다. $(1 ≤ N ≤ 10^9)$

출력

첫째 줄에 문제의 정답을 출력한다.

예제

예제 입력
3
예제 출력
6

힌트

$\&$와 $⊕$는 각각 Bitwise AND, XOR 연산을 의미하며, $>>$는 시프트 연산자이다.
