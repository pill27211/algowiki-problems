End Of File

난이도 1 ⏱ 1.000s 🧠 128 MB
수학 구현 사칙연산

문제

End Of File(이하 EOF)이란, 단어 뜻 그대로 데이터 파일로부터 더 이상 읽을 수 있는 데이터가 없음을 나타낸다.

언어마다 EOF를 처리하는 문법이 상이할테니, 사용 언어에 맞게 EOF 처리 방식을 배워보도록 하자.

입력

기약 없이 두 개의 정수 $A, B$가 공백으로 구분되어 주어진다. $(-10^9 ≤ A, B ≤ 10^9)$

출력

$A, B$가 주어질 때마다 $A+B$의 결과를 차례대로 출력한다.

예제

예제 입력
1 5

2 5

-3 2
예제 출력
6

7

-1

앞으로 알고리즘 문제를 풀다보면, 입력의 크기가 주어지지 않는 문제들을 종종 만날 수 있다. 이를 대비해 사용 언어에 맞는 EOF 처리 방식을 이 문제를 시작으로 배워보도록 하자.
C 

흔히 사용하는 scanf()도, 사실 성공적으로 입력된 항목의 개수를 반환한다. 이를 이용해 다음의 방식으로 EOF를 판단할 수 있다.



// 일반적으로 정의된 EOF(-1)와 비교

while(scanf("%d %d", &a, &b) != EOF)

{

    ...

}



// EOF가 -1임을 이용해 비트 연산으로 간단히 표현

while(~scanf("%d %d", &a, &b))

{

    ...

}
C++ 

C++의 cin은 기본적으로 스트림을 반환한다. 이를 while문에 넣을 경우, bool형으로의 묵시적 변환을 통해 EOF를 판단할 수 있다.

while(cin >> a >> b)

{

    ...

}
