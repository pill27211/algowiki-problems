#1037

가장 긴 연속 단조 구간

난이도 3 ⏱ 1.000s 🧠 128 MB
구현 다이나믹 프로그래밍

문제

모든 요소가 정수이고 길이가 $n$인 수열 $a_1, a_2, ... , a_n$이 주어진다. 이 수열의 연속 구간 중 가장 긴 '단조 증가 구간'과 '단조 감소 구간'의 길이를 각각 구해보자. 수열 $a_n$의 어떤 연속 구간 $[l, r]$이 다음을 만족한다면 $[l, r]$을 단조 구간이라고 한다.

  • $a_l ≤ a_{l+1} ≤ ... ≤ a_{r-1} ≤ a_r$ 또는 $a_l ≥ a_{l+1} ≥ ... ≥ a_{r-1} ≥ a_r$가 성립한다.

입력

첫째 줄에 수열의 길이 $n$이 주어진다. $(1 ≤ n ≤ 200,000)$

둘째 줄에 $a_1, a_2, ... , a_n$이 공백으로 구분되어 주어진다. $(-10^9 ≤ a_i ≤ 10^9)$

출력

첫째 줄에  가장 긴 '단조 증가 구간'과 '단조 감소 구간'의 길이를 공백으로 구분하여 순서대로 출력한다.

예제

예제 입력
10

-1 2 3 6 4 7 4 3 0 -1
예제 출력
4 5

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
$a_1, a_2, ... , a_n$을 한 번 순회하여 답을 계산해낼 수 있다. 

max_increase_len = 1

max_decrease_len = 1

in_cur = 1

de_cur = 1



for i    ← 2 to n

    if a[i] >= a[i - 1]

        in_cur++

    else

        in_cur = 1



    if a[i] <= a[i - 1]

        de_cur++

    else

        de_cur = 1



    max_increase_len = max(max_increase_len, in_cur)

    max_decrease_len = max(max_decrease_len, de_cur)
