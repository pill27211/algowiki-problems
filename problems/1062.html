#1062

소수와 쿼리 (Large)

난이도 5 ⏱ 2.000s 🧠 512 MB
수학 정수론 소수 판정 에라토스테네스의 체 이분 탐색 누적 합 쿼리형 문제

문제

다음과 같은 쿼리를 처리하는 프로그램을 작성해보자.

  • $l$ $r$ : $[l, r]$에 존재하는 소수의 개수를 출력한다.

입력

첫째 줄에 쿼리의 개수 $Q$개 주어진다. $(1 ≤ Q ≤ 10^5)$

둘째 줄부터 $Q$개의 줄에 걸쳐 $l, r$이 공백으로 구분되어 주어진다. $(1 ≤ l ≤ r ≤ 10^6)$

출력

쿼리가 주어질 때마다 그에 맞는 답을 차례대로 출력한다.

예제

예제 입력
3

3 8

5 15

11 11
예제 출력
3

4

1

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
문제의 제한이 작지 않으므로, 소수 판정을 빠르게 수행할 수 있어야 한다. 나아가 임의의 구간 속 소수의 개수 역시 빠르게 구할 수 있어야 한다.
첫번째 문제는 에라토스테네스의 체를 이용해서, 두번째 문제는 누적 합을 이용해서 해결할 수 있다.
다음 두 배열을 전처리 하자. 

isPrime[i] : i가 소수라면 1, 소수가 아니라면 0

prefix[i] : [1, i]에 존재하는 소수의 개수
체를 돌리면서 동시에 누적 합 배열을 전처리해도 되고, 체를 먼저 돌린 후 누적 합 배열을 전처리 해도 된다.
결과적으로 전처리 $O(rloglogr)$, 누적 합을 이용해 쿼리당 $O(1)$에 응답하여 문제를 총 $O(Q + rloglogr)$에 해결할 수 있다.
