#1195

집합과 쿼리 6

난이도 7 ⏱ 3.000s 🧠 512 MB
비트 집합 비트마스킹 쿼리형 문제

문제

$1, 2, ... , N$의 번호가 매겨진 $N$개의 공집합이 있다. 아래의 쿼리를 수행하는 프로그램을 작성해보자.

  • $1$ $i$ $k$ : $i$번 집합에 정수 $k$를 추가한다. $k$가 이미 집합 $i$에 속한다면 아무것도 수행하지 않는다.
  • $2$ $i$ $j$ : $i$번 집합과 $j$번 집합이 공통으로 가지고 있는 정수의 개수를 출력한다.
  • $3$ $i$ $j$ : $i$번 집합과 $j$번 집합 그 어디에도 속하지 않은 정수의 개수를 출력한다.

$3$번 쿼리에서 취급하는 정수는 $1$ 이상 $100,000$ 이하의 정수들이다.

입력

첫째 줄에 집합의 수 $N$과 쿼리의 개수 $Q$가 공백으로 구분되어 주어진다. $(2 ≤ N, ≤ 1,000; 1 ≤ Q ≤ 200,000)$

둘째 줄부터 $Q$개의 줄에 걸쳐 임의의 쿼리가 주어진다.

입력으로 주어지는 모든 수는 정수이며, $(1 ≤ i, j ≤ N; i ≠ j; 1 ≤ k ≤ 100,000)$ 를 만족한다.

출력

출력을 요구하는 쿼리가 주어질 때마다 그에 맞는 정답을 차례대로 출력한다.

예제

예제 입력
5 9

1 1 1

1 1 3

1 2 2

2 1 2

1 3 3

2 1 3

3 1 2

3 1 3

3 4 5
예제 출력
0

1

99997

99998

100000
