#1048

부분 집합의 합 문제

난이도 4 ⏱ 1.000s 🧠 128 MB
브루트포스 알고리즘 백트래킹

문제

$NP$-$complete$ 문제에 속하는 대표 문제 중 하나인 부분 집합의 합 문제를 간소화하여 풀어보자. 문제는 다음과 같다.

  • $n$개의 정수로 이루어진 수열 $a_1, a_2, ... , a_n$이 있다. 고른 수들의 합이 $S$가 되도록 하나 이상의 수를 고를 때, 가능한 경우의 수가 총 몇가지나 있겠는가?

입력

첫째 줄에 $n$과 $S$가 공백으로 구분되어 주어진다. $(1 ≤ n ≤ 20$ $;$ $|S| ≤ 100)$

둘째 줄에 $a_1, a_2, ... , a_n$이 공백으로 구분되어 주어진다. $(|a_i| ≤ 100)$

출력

첫째 줄에 문제의 정답을 출력한다.

예제

예제 입력
5 6

1 2 3 4 5
예제 출력
3

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
이 문제는 $NP$ 문제지만, $n ≤ 20$ 이므로 완전 탐색을 통해 해결할 수 있다.
다음은 이 문제를 해결하는 완전 탐색의 예시 코드이니 참고하도록 하자.

solve(sum, i) ← a[1], a[2], ... , a[i]까지 고려했고, 지금까지의 합이 sum

{

    res                                ← sum이 S와 같으면 1, 다르면 0

    while ++i <= n                     ← 다음 인덱스가 유효하다면

        res += solve(sum + a[i], i)    ← 분기해본다.



    return res

}



ans : solve(a[1], 1) + solve(a[2], 2) + ... + solve(a[n], n)
