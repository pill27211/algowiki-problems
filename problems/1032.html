#1032

최대공약수와 최소공배수 (Small)

난이도 2 ⏱ 1.000s 🧠 128 MB
수학 정수론 유클리드 호제법

문제

두 양의 정수 $x, y$가 주어질 때, 최대공약수와 최소공배수를 각각 구해보자.

입력

첫째 줄에 테스트 케이스의 수 $T$가 주어진다. $(1 ≤ T ≤ 1,000)$

둘째 줄부터 $T$개의 줄에 걸쳐 $x, y$가 공백으로 구분되어 주어진다. $(1 ≤ x, y ≤ 1,000)$

출력

각 테스트 케이스마다 $gcd(x, y)$, $lcm(x, y)$의 값을 공백으로 구분하여 출력한다.

예제

예제 입력
3

3 5

6 12

4 4
예제 출력
1 15

6 12

4 4

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
두 정수 $x, y$의 공약수는 말그대로 $x$의 약수임과 동시의 $y$의 약수인 수이다. 또한, 그러한 수들 중에서 가장 큰 수가 곧 $x$와 $y$의 최대 공약수이다. 이를 구하는 가장 기본적인 방법은 다음과 같을 것이다. 

gcd(x, y)

    res      ← 결과를 담을 변수

    for i    ← 1 to min(x, y)

        if x % i == 0 and y % i == 0

            res = i

    return res
최대공약수와 최소공배수 사이의 관계는 다음으로 표현할 수 있다. 

lcm(x, y) = x * y / gcd(x, y)
위의 방법으로 최대공약수와 최소공배수를 구한다면 $O(min(x, y))$의 시간복잡도를 갖게 되지만, 본 문제의 제한을 보면 이 방법으로도 충분히 통과할 수 있다.
