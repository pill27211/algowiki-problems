#1229

이항계수의 합 $8$

난이도 5 ⏱ 1.000s 🧠 512 MB
수학 조합론 다이나믹 프로그래밍

문제

양의 정수 $n$이 주어질 때, 다음 값을 구하여라.

  • $\sum\limits_{k=1}^n \Bigg\{ \left(\begin{array}{c}{k+0}\\ 0\end{array}\right) + \left(\begin{array}{c}{k+1}\\ 1\end{array}\right) + \left(\begin{array}{c}{k+2}\\ 2\end{array}\right) + ... + \left(\begin{array}{c}{k+k}\\ k\end{array}\right) \Bigg\}$

입력

첫째 줄에 양의 정수 $n$이 주어진다. $(1 ≤ n ≤ 1,000)$

출력

첫째 줄에 문제의 답을 출력한다. 단, 수가 너무 커질 수 있으니 $10^9+7$로 나눈 나머지를 출력한다.

예제

예제 입력
2
예제 출력
13

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
$n ≤ 1,000$ 이므로, 다이나믹 프로그래밍을 이용한 $O(n^2)$의 전처리를 통해 가능한 모든 $\left(\begin{array}{c}n\\ r\end{array}\right)$의 값을 $O(1)$에 구할 수 있다. 

dp[i][j] = dp[i - 1][j] + dp[i - 1][j - 1]
이제 주어진 수식을 계산할 때 한 쌍의 조합을 $O(1)$에 계산할 수 있으니 문제를 $O(n^2)$에 해결할 수 있다.
