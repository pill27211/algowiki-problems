#1088

소인수분해 (Small)

난이도 2 ⏱ 1.000s 🧠 512 MB
수학 정수론 소수 판정

문제

양의 정수 $n$이 주어진다. $n$을 소인수분해하는 프로그램을 작성해 보자.

입력

첫째 줄에 양의 정수 $n$이 주어진다. $(2 ≤ n ≤ 10^6)$

출력

첫째 줄에 $n$을 소인수분해한 결과를 공백으로 구분하여 출력한다. 단, 소인수가 $2$개 이상일 경우 오름차순으로 출력해야 한다.

예제

예제 입력
12
예제 출력
2 2 3

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
$n$을 소인수분해 하는 가장 나이브한 방식을 떠올려보자. 이는 다음과 같을 것이다. 

while n > 1

    for i    ← 2 to n

        if n % i == 0

            print i

            n /= i

            break
이 방법은 최악의 경우 $O(n)$의 시간 복잡도를 갖지만, $(2 ≤ n ≤ 10^6)$ 이므로 충분히 문제를 해결할 수 있다.
만약 $n$이 훨씬 크다면 어떻게 해결해야 할까?
