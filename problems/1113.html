#1113

$a_i + a_j = k$ $(1)$

난이도 2 ⏱ 1.000s 🧠 512 MB
브루트포스 알고리즘

문제

길이 $n$의 수열 $a_1, a_2, ... , a_n$과 $k$가 주어진다. $1 ≤ i < j ≤ n$인 $i, j$에 대해 $a_i$ + $a_j$ = $k$를 만족하는 $(i, j)$쌍의 개수를 구하여라.

입력

첫째 줄에 수열의 길이 $n$과 정수 $k$가 공백으로 구분되어 주어진다. $(1 ≤ n, k ≤ 2,000)$

둘째 줄에 $a_1, a_2, ... , a_n$이 공백으로 구분되어 주어진다. $(1 ≤ a_i ≤ 2,000)$

입력으로 주어지는 모든 수는 정수이며, $a_i$는 유일하다.

출력

첫째 줄에 문제의 정답을 출력한다.

예제

예제 입력
5 6

1 2 3 4 5
예제 출력
2

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
이 문제를 해결하는 가장 기본적인 방식을 떠올려보자. 그것은 바로 가능한 모든 쌍을 조사해 보는 것이다.
이 경우 $O(n^2)$의 시간복잡도를 갖지만, $(1 ≤ n ≤ 2,000)$ 이므로 충분히 본 문제를 해결할 수 있다. 

cnt          ← 0

for i        ← 1 to n

    for j    ← i+1 to n

        if a[i] + a[j] == k

            cnt++
만약 $n$이 십만 단위라면 어떻게 문제를 해결해야 할까?
