#1098

$\sum\limits_{i=1}^n i$ (Small)

난이도 1 ⏱ 1.000s 🧠 512 MB
구현 수학

문제

양의 정수 $n$이 주어진다. $\sum\limits_{i=1}^n i$의 값을 출력하자.

입력

첫째 줄에 양의 정수 $n$이 주어진다. $(1 ≤ n ≤ 10,000)$

출력

첫째 줄에 $\sum\limits_{i=1}^n i$의 값을 출력한다.

예제

예제 입력
10
예제 출력
55

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
$1$부터 $n$까지의 합을 구하는 방법을 생각해 보자. 결과를 저장하는 변수를 하나 두고, $1$부터 $n$까지 반복문을 순회하며 더해줄 수 있다.
이 방법은 $O(n)$의 시간 복잡도를 가지는데, $1 ≤ n ≤ 10,000$ 이므로 문제를 충분히 해결할 수 있다.
$n$이 훨씬 크다면, 어떠 방법을 사용해야 할지도 고민해보도록 하자.
