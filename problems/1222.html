#1222

이항계수의 합 $2$

난이도 3 ⏱ 1.000s 🧠 512 MB
수학 조합론

문제

양의 정수 $n$이 주어질 때, 다음 값을 구하여라.

  • $\left(\begin{array}{c}n\\ 0\end{array}\right) - \left(\begin{array}{c}n\\ 1\end{array}\right) + \left(\begin{array}{c}n\\ 2\end{array}\right) - \left(\begin{array}{c}n\\ 3\end{array}\right) + ... +$ $(-1)^n\left(\begin{array}{c}n\\ n\end{array}\right)$

입력

첫째 줄에 양의 정수 $n$이 주어진다. $(1 ≤ n ≤ 10^{18})$

출력

첫째 줄에 문제의 답을 출력한다.

예제

예제 입력
2
예제 출력
0

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
본문에 정의된 식의 값은 곧 $0$과 같다. 이는 이항 정리 $(x+y)^n = \sum\limits_{i=0}^n \left(\begin{array}{c}n\\ r\end{array}\right)x^{n-r}y^r$를 이용해 증명할 수 있다.
