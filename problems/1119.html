#1119

$mex(a_n)$

난이도 2 ⏱ 1.000s 🧠 512 MB
구현 정렬

문제

길이 $n$의 수열 $a_n$에 대하여 $mex(a_n)$은 다음으로 정의되는 값이다.

  • $mex(a_n)$ : 수열 $a_n$에 존재하지 않는 가장 작은 음이 아닌 정수
$a_n$이 주어질 때, $mex(a_n)$의 값을 구하여라.

입력

첫째 줄에 수열의 길이 $n$이 주어진다. $(1 ≤ n ≤ 100,000)$

둘째 줄에 $a_1, a_2, ... , a_n$이 공백으로 구분되어 주어진다. $(0 ≤ a_i ≤ n)$

출력

첫째 줄에 $mex(a_n)$의 값을 출력한다.

예제

예제 입력
3

2 0 3
예제 출력
1

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
아래와 같은 배열을 하나 두자. 

count[i] : 주어지는 수열에 i가 존재한다면 1, 존재하지 않으면 0
위 배열에 기록이 끝났다면 $0$부터 수를 하나씩 올려보며 $mex$값이 될 수 있는지 판단하면 된다. 

for i    ← 0 to n

    if count[i] == 0

        print 'i'

        exit
