#1138

진수와 남훈이의 휴전 돌입

난이도 5 ⏱ 1.000s 🧠 512 MB
그리디 알고리즘 누적 합

문제

격렬히 싸운 두 세력은 휴전에 돌입하기로 결정했다. 다만, $n$개의 보급품을 두고 배급에 관해 아직 협의점을 찾지 못하고 있는 상태이다. 따라서 이들이 어서 휴전에 돌입할 수 있도록 아래 규칙에 의거하여 가장 공평하게 배급되는 경우를 찾아주려고 한다.

  1. 각 보급품에는 $1, 2, ... , n$의 고유한 번호가 할당되어 있으며 $i$번째 보급품은 $v_i$의 가치를 가진다.
  2. 진수의 세력은 $1$번부터 번호가 증가하는 연속적인 보급품들을 취할 수 있다.
  3. 남훈이의 세력은 $n$번부터 번호가 감소하는 연속적인 보금품들을 취할 수 있다.
  4. 각 보급품은 두 세력 중 반드시 하나의 세력에만 배급되어야 하며, 배급되지 않은 보급품은 없어야 한다.

$9$개의 보급품이 있다고 가정해보자. $[$진수의 세력$]$ : $[$남훈이의 세력$]$에 대해 $[1, 4] : [5, 9]$ 또는 $[1, 3] : [4, 9]$ 와 같이 양 끝 점을 포함하는 두 개의 연속된 구간으로 나눌 수 있을 것이다. 이때, 배급의 공평한 정도는 각 구간에 속한 보급품 가치의 합의 차이로 정의되고 다음을 만족하는 값이 바로 가장 공평한 배급이 된다.

  • $1 ≤ i < n$인 $i$에 대해 $min(|\sum\limits_{j=1}^i v_j - \sum\limits_{l={i+1}}^n v_l|)$

보급품 $n$개에 대한 가치가 주어질 때, 가장 공평하게 배급되는 경우를 찾는 프로그램을 작성해주자.

입력

첫째 줄에 보급품의 개수 $n$이 주어진다. $(2 ≤ n ≤ 200,000)$

둘째 줄에 $v_1, v_2, ... , v_n$이 공백으로 구분되어 주어진다. $(1 ≤ v_i ≤ 10^9)$

출력

첫째 줄에 문제에서 정의한 $min(|\sum\limits_{j=1}^i v_j - \sum\limits_{l={i+1}}^n v_l|)$의 값을 출력한다.

예제

예제 입력
9

4 1 2 5 3 2 1 2 3
예제 출력
1

힌트

$i = 4$로 잡으면 진수의 세력에 $[1, 4]$번 보급품, 남훈이의 세력에 $[5, 9]$번 보급품이 배급됨에 따라 $\sum\limits_{j=1}^4 v_j = 12$, $\sum\limits_{l=5}^9 v_l = 11$ 가 된다.

이 경우 $min(|\sum\limits_{j=1}^i v_j - \sum\limits_{l={i+1}}^n v_l|) = 1$이 되고 이보다 공평하게 배급하는 경우는 존재하지 않는다.

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
다음 두 배열을 전처리 하자. 

pre[i] : v[1] + v[2] + ... + v[i]

suf[i] : v[i] + v[i+1] + ... + v[n]
이 두 배열을 적절히 이용하면 다음 식이 성립한다.
  • $|\sum\limits_{j=1}^i v_j - \sum\limits_{l={i+1}}^n v_l| = |pre[i] - suf[i+1]|$
    • 이제 $1, 2, ... , n$-$1$을 돌아보며 $min(|pre[i] - suf[i+1]|)$의 값을 찾아주면 되겠다.
    $pre, suf$를 전처리 하는 데에 $O(n)$, 답을 찾는 데에 $O(n)$으로 문제를 총 $O(n)$에 해결할 수 있다.
