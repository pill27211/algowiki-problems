#1081

다섯 개의 정수

난이도 4 ⏱ 1.000s 🧠 512 MB
이분 탐색 매개 변수 탐색

문제

다섯 개의 정수 $a, b, c, d, e$와 $k$가 주어진다. 최대 $k$번 만큼 아래 연산을 수행할 수 있을 때, $max(a, b, c, d, e)$의 값을 최대한 최소화해보자.

  • 임의의 수를 골라 $1$만큼 감소 시킨다. 단, 수가 $0$보다 작아질 순 없다.

입력

첫째 줄에 정수 $a, b, c, d, e, k$가 공백으로 구분되어 차례대로 주어진다. $(0 ≤ a, b, c, d, e, k ≤ 10^9)$

출력

첫째 줄에 최대 $k$번 만큼 연산을 수행하여 만들 수 있는 가장 작은 $max(a, b, c, d, e)$의 값을 출력한다.

예제

예제 입력
3 4 5 6 7 8
예제 출력
4

힌트

입력 예시 $1$

  • $c, d, e$에 각각 $1, 2, 3$번 연산을 수행하면 $max(a, b, c, d, e) = 4$가 되고, 이보다 최댓값을 작게 만드는 방법은 존재하지 않는다.

입력 예시 $2$

  • $a, c, e$에 각각 $4, 1, 3$번 연산을 수행하면 $max(a, b, c, d, e) = 1$이 되고, 이보다 최댓값을 작게 만드는 방법은 존재하지 않는다.

수들의 범위가 크므로 나이브하게 답을 계산할 순 없다. 다음과 같이 결정 문제를 정의해보자.

  • $decision(m)$ : $max(a, b, c, d, e)$의 값을 $m$으로 만들 수 있는가?
각 결정 문제는 $a, b, c, d, e$ 각각이 $m$보다 얼마나 큰지를 누적해 주고, 전체 누적값이 $k$ 이하 인지로 보아 판단할 수 있다.

적당한 $m$을 찾는 데에 $O(logk)$, 각 결정 문제를 푸는 데에 $O(1)$로 총 $O(logk)$의 시간 복잡도로 문제를 해결할 수 있다.
