#1227

이항계수의 합 $6$

난이도 8 ⏱ 1.000s 🧠 512 MB
수학 조합론 분할 정복

문제

양의 정수 $n$이 주어질 때, 다음 값을 구하여라.

  • $\left(\begin{array}{c}n\\ 0\end{array}\right) + \left(\begin{array}{c}{n-1}\\ 1\end{array}\right) + \left(\begin{array}{c}{n-2}\\ 2\end{array}\right) + ... + \left(\begin{array}{c}0\\ n\end{array}\right)$

입력

첫째 줄에 양의 정수 $n$이 주어진다. $(1 ≤ n ≤ 10^{18})$

출력

첫째 줄에 문제의 답을 출력한다. 단, 수가 너무 커질 수 있으니 $10^9 + 7$로 나눈 나머지를 출력한다.

예제

예제 입력
2
예제 출력
2
