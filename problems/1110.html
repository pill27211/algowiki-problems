#1110

서로 다른 경로의 개수 3

난이도 7 ⏱ 1.000s 🧠 512 MB
다이나믹 프로그래밍

문제

$2$차원 맵의 세로, 가로 길이가 주어진다. $(1, 1)$에서 중간 지점 $(p, q)$를 거친 뒤 $(n, m)$에 도달하는 서로 다른 경로의 개수는 몇 개나 될까?

$(i, j)$에서 $(i+1, j)$ 또는 $(i, j+1)$로 이동할 수 있다.


입력

첫째 줄에 맵의 세로 길이를 의미하는 $n$과 가로 길이를 의미하는 $m$이 공백으로 구분되어 주어진다. $(1 ≤ n, m ≤ 1,000)$

둘째 줄에 거쳐야 하는 중간 지점의 좌표 $p, q$가 공백으로 구분되어 주어진다. $(1 ≤ p ≤ n; 1 ≤ q ≤ m)$

$(1, 1)$ 또는 $(n, m)$이 중간 지점인 경우는 존재하지 않는다.

출력

첫째 줄에 $(1, 1)$에서 $(p, q)$를 거친 뒤 $(n, m)$에 도달하는 서로 다른 경로의 개수를 출력한다. 단, 수가 너무 커질 수 있으니 $10^9+7$로 나눈 나머지를 출력한다.

예제

예제 입력
5 5

3 3
예제 출력
36
