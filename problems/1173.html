#1173

Inversion Counting (Small)

난이도 2 ⏱ 1.000s 🧠 512 MB
구현

문제

유명한 문제 중 하나인 Inversion Counting 문제를 풀어보자. 모든 원소가 고유한 수열  $a_1, a_2, ... , a_n$에 대해 아래의 값을 구하면 된다.

  • $1 ≤ i < j ≤ n$인 순서쌍 $(i, j)$에 대해 $a_i > a_j$를 만족하는 쌍의 개수

입력

첫째 줄에 수열의 길이 $n$이 주어진다. $(2 ≤ n ≤ 2,000)$

둘째 줄에 $a_1, a_2, ... , a_n$이 공백으로 구분되어 주어진다. $(1 ≤ a_i ≤ n)$

출력

첫째 줄에 문제의 정답을 출력한다.

예제

예제 입력
7

1 3 7 5 4 2 6
예제 출력
8

힌트

$(i, j) = (2, 6), (3, 4), (3, 5), (3, 6), (3, 7), (4, 5), (4, 6), (5, 6)$ 로 총 $8$가지가 있다.

이 문제를 해결하는 가장 나이브한 방식을 생각해보자. 이는 곧 가능한 모든 쌍에 대해 검사해주는 것이다.
$O(n^2)$의 시간복잡도를 갖지만 $2 ≤ n ≤ 2,000$ 이므로 충분히 문제를 해결할 수 있다. 

cnt = 0

for i           ← 1 to n

    for j       ← i+1 to n

        if a[i] > b[j]

            cnt_J++
