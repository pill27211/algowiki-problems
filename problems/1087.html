#1087

서로 다른 경로의 개수 1

난이도 4 ⏱ 1.000s 🧠 512 MB
수학 다이나믹 프로그래밍 조합론

문제

$2$차원 맵의 세로, 가로 길이가 주어진다. $(1, 1)$에서 $(n, m)$에 도달하는 서로 다른 경로의 개수는 몇 개나 될까?

$(i, j)$에서 $(i+1, j)$ 또는 $(i, j+1)$로 이동할 수 있다.


입력

첫째 줄에 맵의 세로 길이를 의미하는 $n$과 가로 길이를 의미하는 $m$이 공백으로 구분되어 주어진다. $(1 ≤ n, m ≤ 1,000)$

출력

첫째 줄에 $(1, 1)$에서 $(n, m)$에 도달하는 서로 다른 경로의 개수를 출력한다. 단, 수가 너무 커질 수 있으니 $10^9+7$로 나눈 나머지를 출력한다.

예제

예제 입력
3 4
예제 출력
10

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.

$O(nm)$ $DP$로 문제를 해결할 수 있다. 다음과 같이 정의하자.

  • $dp[i][j]$ : $(1, 1)$에서 $(i, j)$에 도달하는 서로 다른 경로의 개수
다음으로 문제에서 정의한 이동 방식에 따라, 다음과 같이 관계식을 쓸 수 있다.
  • $dp[i][j] = dp[i - 1][j] + dp[i][j - 1]$ $(dp[1][1] = 1)$
이를 이용해 모든 상태를 계산한 뒤 $dp[n][m]$을 출력해주면 되겠다. 나머지 연산에 유의하자.
