#1064

문자열의 점수

난이도 2 ⏱ 1.000s 🧠 512 MB
구현 문자열 사칙연산

문제

알파벳 소문자, 대문자으로만 이루어진 문자열 $S$가 주어진다. 아래 기준에 의거하여 $S$의 점수를 구해보자.

  • $S$의 $i$번째 문자가
    • 소문자라면 $a = 1, b = 2, ... , z = 26$점이다.
    • 대문자라면 $A = -1, B = -2, ... , Z = -26$점이다.

입력

첫째 줄에 문자열 $S$가 주어진다. $(1 ≤ |S| ≤ 1,000)$

출력

첫째 줄에 $S$의 점수를 출력한다.

예제

예제 입력
AlgoWiki
예제 출력
39

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
점수를 기록할 변수를 하나 두고, $S$를 순회하며 문제의 규칙대로 계산해주면 된다. 

아스키 코드에서 소문자 알파벳은 97 이상 122 이하이다.

아스키 코드에서 대문자 알파벳은 65 이상 90 이하이다.



ans = 0

for i    ← 1 to |S|

    if S[i] >= 97 && S[i] <= 122

        ans += S[i] - 96

    else

        ans -= S[i] - 64
