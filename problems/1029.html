#1029

집합과 쿼리 1

난이도 2 ⏱ 1.000s 🧠 128 MB
구현 쿼리형 문제

문제

원소가 모두 양의 정수인 집합 $U$ $=$ {$e_1, e_2, ... , e_N$} 가 주어진다.

아래 쿼리를 수행하는 프로그램을 작성해보자.

  • $k$ : 집합 $U$에 정수 $k$가 속해 있다면 $1$, 속해있지 않다면 $0$을 출력한다. $(1 ≤ k ≤ 10,000)$

입력

첫째 줄에 집합의 크기 $N$과 쿼리의 개수 $Q$가 공백으로 구분되어 주어진다. $(1 ≤ N ≤ 2,000; 1 ≤ Q ≤ 10,000)$

둘째 줄에 $e_1, e_2, ... , e_N$이 공백으로 구분되어 주어진다. $(1 ≤ e_i ≤ 10,000)$

셋째 줄부터 $Q$개의 줄에 걸쳐 쿼리가 주어진다.

출력

각 쿼리가 주어질 때마다 그에 맞는 정답을 차례대로 출력한다.

예제

예제 입력
5 3

1 2 3 4 5

3

7

1
예제 출력
1

0

1

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
쿼리가 주어질 때마다 집합을 순회하며 $k$가 집합에 속해 있는지 판단할 수 있다. 이 경우 $O(NQ)$의 시간복잡도를 갖지만 문제의 제한 상 충분하다. 한편, $1 ≤ e_i < 10,000$인 점을 이용해 카운트 배열을 운용할 수 있다. 

count[i] : i가 집합 U에 속해 있다면 count[i] = 1, 아니면 0
이 경우 쿼리가 주어질 때마다 $count[i]$의 값을 보면 존재 여부를 바로 파악할 수 있으므로 $O(Q)$의 시간복잡도를 갖는다.
