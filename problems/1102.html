#1102

등급 판단하기

난이도 1 ⏱ 1.000s 🧠 512 MB
구현

문제

$[1, 100]$에 속한 점수 $s$가 주어진다. 아래 기준에 의거하여 등급을 판단하자.

  • $95 ≤ s ≤ 100$ : $A+$
  • $90 ≤ s ≤ 94$ : $A$
  • $85 ≤ s ≤ 89$ : $B+$
  • $80 ≤ s ≤ 84$ : $B$
  • $75 ≤ s ≤ 79$ : $C+$
  • $70 ≤ s ≤ 74$ : $C$
  • $65 ≤ s ≤ 69$ : $D+$
  • $60 ≤ s ≤ 64$ : $D$
  • $1 ≤ s ≤ 59$ : $F$

입력

첫째 줄에 점수 $s$가 주어진다. $(1 ≤ s ≤ 100)$

출력

첫째 줄에 $s$를 등급으로 환산한 결과를 출력한다.

예제

예제 입력
95
예제 출력
A+
