#1218

수열 출력하기 2

난이도 6 ⏱ 2.000s 🧠 512 MB
수학 정수론 해 구성하기

문제

양의 정수 $n$이 주어진다. 다음을 만족하는 길이 $n$의 수열 $a_1, a_2, ... , a_n$을 출력하여라.

  • 모든 $a_i$는 $1 ≤ a_i ≤ 10^6$인 정수이며 중복되지 않아야 한다.
  • $1 ≤ i, j ≤ n$이고 $i ≠ j$인 가능한 모든 $(a_i, a_j)$쌍에 대해, $gcd(a_i, a_j) = 1$

입력

첫째 줄에 수열의 길이를 의미하는 정수 $n$이 주어진다. $(1 ≤ n ≤ 50,000)$

출력

첫째 줄에 문제의 조건을 만족하는 길이 $n$의 수열을 공백으로 구분하여 출력한다. 만약 조건을 만족하는 수열이 여러 개라면 그 중 아무거나 출력해도 정답으로 인정된다.

예제

예제 입력
3
예제 출력
1 2 3

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
$gcd(a_i, a_j) = 1$이라는 것은, $a_i$와 $a_j$가 $2$ 이상의 소인수를 공유하지 않는다는 뜻과 같다. $(a_i ≠ a_j)$
$n$개의 소수를 생각해보자. 그들에게는 $1$과 자기 자신을 제외한 소인수가 존재하지 않으며, 어떤 두 쌍을 골라 잡아도 최대공약수는 $1$이다.
