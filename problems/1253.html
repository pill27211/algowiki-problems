간단한 문제 2

난이도 7 ⏱ 1.000s 🧠 512 MB
수학

문제

간단한 문제를 하나 풀어보자. 길이 $n$의 수열 $a_1, a_2, ... , a_n$이 주어질 때, 다음 값을 구하면 된다.

  • $\sum\limits_{i=1}^{n}\sum\limits_{j=i}^n\sum\limits_{k=i}^j a_k$

입력

첫째 줄에 수열의 길이를 의미하는 정수 $n$이 주어진다. $(1 ≤ n ≤ 200,000)$

둘째 줄에 $a_1, a_2, ... , a_n$이 공백으로 구분되어 주어진다. $(1 ≤ a_i ≤ 10,000)$

출력

첫째 줄에$\sum\limits_{i=1}^{n}\sum\limits_{j=i}^n\sum\limits_{k=i}^j a_k$의 값을 출력한다.

예제

예제 입력
4

1 2 3 4
예제 출력
50
