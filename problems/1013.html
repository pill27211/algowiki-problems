#1013

피보나치 수 2

난이도 3 ⏱ 1.000s 🧠 512 MB
수학 다이나믹 프로그래밍

문제

피보나치 수 $F_n$은 다음으로 정의되는 수열이다.

$0$번째 항 $F_0 = 0$을 시작으로 초항을 나열해보면 다음과 같을 것이다.

  • $0, 1, 1, 2, 3, 5, 8, 13, ...$

$n$이 주어질 때, $n$번째 피보나치 수 $F_n$을 구해보자.

입력

첫째 줄에 음이 아닌 정수 $n$이 주어진다. $(0 ≤ n ≤ 10^6)$

출력

첫째 줄에 $F_n$을 출력한다. 단, 수가 너무 커질 수 있으니 $10^9 + 7$로 나눈 나머지를 출력한다.

예제

예제 입력
100
예제 출력
687995182

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.

피보나치 수를 나이브하게 구한다면 $O(2^n)$의 시간복잡도를 갖는다. 가장 큰 문제는 중복 계산을 굉장히 많이 하게 된다는 것이다.

$0 ≤ n ≤ 10^6$임과 상태 전이 식을 이용해 다이나믹 프로그래밍으로 $O(n)$에 문제를 해결할 수 있다.

  • $dp[i]$ : $i$번째 피보나치 수를 $10^9 + 7$로 나눈 나머지
$dp[0] = 0, dp[1] = 1$을 기저 사례로 잡고 $dp[2]$부터 상태 전이 식을 이용해 모든 답을 계산해낼 수 있다.
