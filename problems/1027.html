#1027

소수 판정 (Small)

난이도 2 ⏱ 1.000s 🧠 128 MB
수학 정수론 소수 판정

문제

양의 정수 $x$가 주어진다. $x$가 소수인지 판별해보자.

입력

첫째 줄에 테스트 케이스의 수를 의미하는 $T$가 주어진다. $(1 ≤ T ≤ 1,000)$

둘째 줄부터 $T$개의 줄에 걸쳐 $x$가 주어진다. $(1 ≤ x ≤ 1,000)$

출력

각 테스트 케이스마다 $x$가 소수라면 YES, 소수가 아니라면 NO를 출력한다.

예제

예제 입력
4

2

4

7

10
예제 출력
YES

NO

YES

NO

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
$1$보다 큰 정수 $x$가 $1$과 자기 자신 이외에 약수를 갖지 않는다면 $x$는 소수이다. $x$가 주어질 때마다 $x$가 소수의 정의를 만족하는지 검사하자. 

isPrime(n)

    if n == 1

        return false

    for i    ← 1 to (n / 2) // i가 n의 절반을 넘어가면 이후는 볼 필요가 없다.

        if n % i == 0

            return false

    return true
