#1235

트리 색칠하기

난이도 7 ⏱ 1.000s 🧠 512 MB
다이나믹 프로그래밍 트리 트리 위 다이나믹 프로그래밍

문제

$1, 2, ... , n$의 번호가 고유하게 매겨진 $n$개의 정점이 트리 구조를 이룬다. 아래 기준을 만족하면서 트리를 색칠하려 할 때, 발생하는 비용의 최솟값을 구하여라.

  • $i$번 정점을 빨강색, 초록색, 파랑색으로 칠할 때 각각 $R_i, G_i, B_i$의 비용이 발생한다.
  • 인접한 정점은 서로 다른 색으로 칠해져야 한다. 즉, 간선을 통해 직접적으로 이어진 두 정점을 같은 색으로 칠할 수 없다.

입력

첫째 줄에 정점의 개수를 의미하는 정수 $n$이 주어진다. $(1 ≤ n ≤ 10,000)$

둘째 줄에 $R_1, R_2, ... , R_n$이 공백으로 구분되어 주어진다. $(1 ≤ R_i ≤ 1,000)$

셋째 줄에 $G_1, G_2, ... , G_n$이 공백으로 구분되어 주어진다. $(1 ≤ G_i ≤ 1,000)$

넷째 줄에 $B_1, B_2, ... , B_n$이 공백으로 구분되어 주어진다. $(1 ≤ B_i ≤ 1,000)$

다섯 번째 줄부터 $N-1$개의 줄에 걸쳐 간선 하나가 연결하는 두 정점의 번호가 공백으로 구분되어 주어진다. $(1 ≤ u, v ≤ n; u ≠ v)$

출력

첫째 줄에 조건을 만족하면서 트리를 색칠하는 비용의 최솟값을 출력한다.

예제

예제 입력
6

1 3 1 3 2 1

4 2 2 1 1 2

2 3 2 3 2 3

1 2

1 3

2 4

2 5

3 6
예제 출력
9

다이나믹 프로그래밍으로 해결할 수 있다. 다음과 같이 정의해 보자. 

dp[i][j] : i번 정점을 루트로 하는 서브 트리를 색칠하는 최소 비용. 단, i번 정점의 색은 j

j = 0 → 빨강색

j = 1 → 초록색

j = 2 → 파랑색
이제 문제의 조건에 따라, 다음과 같이 작성해볼 수 있다. 

if dp[i][j] > 0       ← 이미 계산된 상태라면 return

    return



dp[i][j] = k          ← j가 0이면 R[i], 1이면 G[i], 2라면 B[i]

for nxt               ← i와 인접한 정점들을 순회

    if nxt == prev    ← 부모 정점의 값은 취하지 않음

        continue

    if j == 0 dp[i][j] += min(dp[nxt][1], dp[nxt][2])

    if j == 1 dp[i][j] += min(dp[nxt][0], dp[nxt][2])

    if j == 2 dp[i][j] += min(dp[nxt][0], dp[nxt][1])
최종적으로 답은 다음으로 정해진다. 

min(dp[1][0], dp[1][1], dp[1][2])
