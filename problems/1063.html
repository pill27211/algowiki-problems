#1063

문자열 매칭

난이도 1 ⏱ 1.000s 🧠 128 MB
구현 문자열

문제

알파벳 소문자로만 이루어진 문자열 $S$와 $T$가 주어진다. $S$에 $T$가 존재하는지 확인해보자.

입력

첫째 줄에 $S$, 둘째 줄에 $T$가 주어진다. $(1 ≤ |T| ≤ |S| ≤ 1,000)$

출력

첫째 줄에 $S$에 $T$가 존재한다면 YES, 존재하지 않는다면 NO를 출력한다.

예제

예제 입력
algowiki

wiki
예제 출력
YES

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
가장 나이브하게 접근해 보도록 하자.
이는 당연히 $S$의 모든 인덱스에서부터 $|T|$만큼의 부분 문자열을 보며 비교해 보는 방법일 것이다. 시간 복잡도는 $O(|S| \times |T|)$.
문제의 제한이 $1 ≤ |T| ≤ |S| ≤ 1,000$를 만족 하므로, 최악의 경우라도 제한 시간 내에 충분히 동작할 수 있다.

만약 제한이 훨씬 크다면 어떻게 풀어야 할까?
결론부터 말하자면 KMP로 불리는 알고리즘을 사용해 $O(|S| + |T|)$라는 어마무시한 시간 복잡도로 문제를 해결할 수 있다.
궁금하다면 해당 알고리즘을 공부해 보는 것도 좋다.
