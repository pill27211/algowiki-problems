#1184

무향 그래프의 단절선

난이도 9 ⏱ 1.000s 🧠 512 MB
그래프 이론 단절점과 단절선

문제

$N$개의 정점과 $M$개의 간선으로 이루어진 무항 그래프 $G$가 주어진다. $G$의 단절선(Articulation Edge)을 모두 구하여라.

$G$의 어떤 간선 $e$가 단절선이라 함은, 다음을 만족함과 동치이다.

  • 간선 $e$를 제거하면 $G$가 두 컴포넌트 이상으로 분할된다.

입력

첫째 줄에 정점의 개수 $N$과 간선의 개수 $M$이 공백으로 구분되어 주어진다. $(2 ≤ N ≤ 50,000; N-1 ≤ M ≤ 100,000)$

둘째 줄부터 $M$개의 줄에 걸쳐 간선 하나가 연결하는 두 정점의 번호 $u, v$가 공백으로 구분되어 주어진다. $(1 ≤ u, v ≤ N; u ≠ v)$

각 정점에는 $1, 2, ... , N$의 번호가 고유하게 할당되며, $G$는 연결 그래프이다.

출력

첫째 줄에 $G$의 단절선의 개수를 출력한다.

둘째 줄부터 $G$의 단절선들을 사전순으로 출력한다. 단절선은 해당 간선이 잇는 두 정점의 번호 $u, v$를 공백으로 구분하여 출력해야 하며, $u < v$의 형태여야 한다.
