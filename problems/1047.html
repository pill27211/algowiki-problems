#1047

연속된 자연수들의 합 (Large)

난이도 5 ⏱ 1.000s 🧠 128 MB
수학 비트마스킹

문제

양의 정수 $N$이 주어진다. 이 $N$을 연속된 자연수들의 합으로 표현할 수 있을까?

이때 사용되는 자연수는 반드시 두 개 이상이어야 한다.

입력

첫째 줄에 테스트 케이스의 수 $T$가 주어진다. $(1 ≤ T ≤ 10^5)$

둘째 줄부터 $T$개의 줄에 걸쳐 $N$이 주어진다. $(2 ≤ N ≤ 10^9)$

출력

각 테스트 케이스마다 $N$을 연속된 자연수들의 합으로 표현할 수 있다면 YES, 표현할 수 없다면 NO를 출력한다.

예제

예제 입력
4

2

3

4

5
예제 출력
NO

YES

NO

YES

힌트

$3$과 $5$는 각각 $1+2$, $2+3$으로 표현할 수 있지만, $2$와 $4$는 두 개 이상의 연속된 자연수들의 합으로 표현할 수 없다.

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
$N$이 $2^k$$(k$는 자연수$)$꼴로 표현된다면, $N$은 결코 연속된 자연수들의 합으로 표현할 수 없다.
