#1034

집합에 속한 문자열

난이도 2 ⏱ 2.000s 🧠 128 MB
구현 문자열 쿼리형 문제

문제

원소가 모두 문자열인 집합 $U$ = {$s_1, s_2, ... , s_N$}가 주어진다.

아래 쿼리를 수행하는 프로그램을 작성해보자.

  • $k$ : 집합 $U$에 문자열 $k$가 속해 있다면 $1$, 속해있지 않다면 $0$을 출력한다. $(1 ≤ |k| ≤ 100)$

$k$는 알파벳 소문자로만 구성된 문자열이다.

입력

첫째 줄에 집합의 크기 $N$과 쿼리의 개수 $Q$가 공백으로 구분되어 주어진다. $(1 ≤ N, Q ≤ 1,000)$

둘째 줄에 $s_1, s_2, ... , s_N$이 공백으로 구분되어 주어진다. $s_i$는 알파벳 소문자로만 구성된 문자열이다. $(1 ≤ |s_i| ≤ 100)$

셋째 줄부터 $Q$개의 줄에 걸쳐 쿼리가 주어진다.

출력

각 쿼리가 주어질 때마다 그에 맞는 정답을 차례대로 출력한다.

예제

예제 입력
5 5

pill kiwi hun hoj algowiki

hun

algokiwi

kiwi

algowiki

hoi
예제 출력
1

0

1

1

0

본 문제를 해결하는 가장 나이브한 방식을 떠올려보자. 이는 곧 쿼리가 주어질 때마다 집합 전체를 순회하며 답을 찾는 것이다.

이 경우 연산량은 쿼리 당 집합의 크기$(N)$와 문자열의 길이$(|s_i|)$에 비례하므로 $O(N|s_i| \times Q)$의 시간복잡도를 갖게 된다.
