#1105

소인수분해 (Large)

난이도 3 ⏱ 1.000s 🧠 512 MB
수학 정수론 소수 판정

문제

양의 정수 $n$이 주어진다. $n$을 소인수분해하는 프로그램을 작성해 보자.

입력

첫째 줄에 양의 정수 $n$이 주어진다. $(2 ≤ n ≤ 10^{12})$

출력

첫째 줄에 $n$을 소인수분해한 결과를 공백으로 구분하여 출력한다. 단, 소인수가 $2$개 이상일 경우 오름차순으로 출력해야 한다.

예제

예제 입력
12
예제 출력
2 2 3

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.

이 문제에서 최악의 경우는 $n$이 소수인 경우이다. $n ≤ 10^{12}$ 이므로, 나이브하게 소인수분해를 진행하면 제한 시간 내에 문제를 해결할 수 없다.

$n$이 두 자연수의 곱 $p \times q$로 표현될 때, $min(p, q) ≤ \sqrt{n}$ 임을 이용하자. 제곱근까지만 본다면 $O(\sqrt{n})$의 시간복잡도를 갖게 되어 제한 시간 내에 충분히 문제를 해결할 수 있다.
