#1150

가장 긴 증가하는 부분 수열 (Large)

난이도 8 ⏱ 1.000s 🧠 512 MB
이분 탐색

문제

수열 $a_n$에 대해, 가장 긴 증가하는 부분 수열의 길이를 구하여라.

입력

첫째 줄에 수열의 길이 $n$이 주어진다. $(1 ≤ n ≤ 200,000)$

둘째 줄에 $a_1, a_2, ... , a_n$이 공백으로 구분되어 주어진다. $(1 ≤ a_i ≤ 10^9)$

출력

첫째 줄에 가장 긴 증가하는 부분 수열의 길이를 출력한다.

예제

예제 입력
5

1 4 2 3 5
예제 출력
4
