#1199

문자열 재조합하기

난이도 1 ⏱ 1.000s 🧠 512 MB
구현 문자열

문제

알파벳 소문자로만 이루어진 문자열 $S_1$이 주어진다. 문자열 $S_2, S_3, S_4$를 다음과 같이 정의할 때, $S_4$를 구해보자.

  • $S_2$ : $S_1$의 홀수번째 문자들을 차례대로 이어붙인 문자열
  • $S_3$ : $S_1$의 짝수번째 문자들을 차례대로 이어붙인 문자열
  • $S_4$ : $S_2$과 $S_3$를 차례대로 이어붙인 문자열

입력

첫째 줄에 알파벳 소문자로만 이루어진 문자열 $S_1$이 주어진다. $(1 ≤ |S_1| ≤ 1,000)$

출력

첫째 줄에 $S_4$를 출력한다.

예제

예제 입력
algowiki
예제 출력
agwkloii

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
문제에서 정의한 $S_2, S_3$를 각각 구해놓고, 최종적으로 둘을 이어 정답을 완성하자. 

S2, S3    ← 빈 문자열

for i      ← 1부터 S1의 길이만큼 증가

	if i가 홀수

		S2 += S1[i]

	else

		S3 += S1[i]
