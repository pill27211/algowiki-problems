#1020

팰린드롬 문자열

난이도 1 ⏱ 1.000s 🧠 128 MB
구현 문자열

문제

팰린드롬 문자열이란, 거꾸로 읽어도 제대로 읽는 것과 같은 문자열을 말한다. 

문자열이 주어질 때, 이 문자열이 팰린드롬 문자열인지 판단해보자.

입력

첫째 줄에 테스트 케이스의 수를 의미하는 $T$가 주어진다. $(1 ≤ T ≤ 1,000)$

둘째 줄부터 $T$개의 줄에 걸쳐, 알파벳 소문자로만 이루어진 문자열 $S$가 주어진다. $(1 ≤ |S| ≤ 100)$

출력

각 테스트 케이스마다 $S$가 팰린드롬 문자열이라면 $1$을, 팰린드롬 문자열이 아니라면 $0$을 출력한다.

예제

예제 입력
3

abba

abc

a
예제 출력
1

0

1

팰린드롬 문자열의 정의를 다시 한번 확인한 후, 어떻게 판정해야 할지 생각해보자. 가장 단순한 방법은 아마 다음과 같을 것이다. 
 주어진 문자열을 뒤집은 후, 원본 문자열과 동일한지 판단한다.
물론 이 방법으로도 충분히 본 문제를 해결할 수 있다. 하지만 팰린드롬의 원리를 생각해 본다면 약간의 최적화를 더할 수 있다.
양 끝에서 시작하는 두 변수 $l, r$을 두고 다음의 과정을 거치면 된다. 

while l < r

    if S[l] != S[r]

        break

    l++, r--
이후, $r ≤ l$가 된다면 주어진 문자열은 팰린드롬 문자열이다.
