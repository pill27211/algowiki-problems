#1131

다이아몬드 찍기

난이도 2 ⏱ 1.000s 🧠 512 MB
구현

문제

정수 $n$이 주어진다. 크기 $n$의 다이아몬드를 출력하라.

입력

첫째 줄에 정수 $n$이 주어진다. $(1 ≤ n ≤ 100)$

출력

크기 $n$의 다이아몬드를 출력한다.

예제

예제 입력
1
예제 출력
*

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
$n$은 곧 다이아몬드의 한 변의 길이와 같다. 이웃한 두 변은 한 점을 공유하므로 행과 열의 개수는 총 $n \times 2 - 1$개이다.
각 행에선 중심 축에서 양방향으로 $1$씩 벌어지거나 좁혀진다. 이를 바탕으로 다양하게 구현할 수 있다. 

for i        ← 1 to n*2-1

    for j    ← 1 to n*2-1 

        if i > n

            if abs(n - j) + 1 == n * 2 - i

                print '*'

            else

                print '.'

        else

            if abs(n - j) + 1 == i

                print '*'

            else

                print '.'

    print '\n'
