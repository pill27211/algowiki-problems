#1003

문자열 뒤집기

난이도 1 ⏱ 1.000s 🧠 128 MB
구현 문자열

문제

알파벳 소문자, 대문자 및 숫자와 공백으로만 이루어진 문자열이 주어진다. 이 문자열을 뒤집어서 다시 출력해보자.

입력

첫째 줄에 문자열 $S$가 주어진다. $(1 ≤ |S| ≤ 10^5)$

$S$는 공백으로 시작하거나 끝나지 않는다.

출력

첫째 줄에 뒤집어진 $S$를 출력한다.

예제

예제 입력
Hello World!
예제 출력
!dlroW olleH

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
C/C++에서 공백이 포함된 문자열을 받기 위해선 약간의 주의가 필요하다.
C 

char str[100005] = {0,}; // 최대 크기보다 조금 더 넉넉하게 잡아 주는 것이 좋다.



// fgets()를 이용한 방법. 개행 문자까지 가져옴을 유의하자.

fgets(str, sizeof str, stdin);

// scanf()의 입력 포맷을 변경하는 방법.

scanf("%[^\n]s", str);
C++ 

std::string str;

getline(std::cin, str);
Java 

Scanner scanner = new Scanner(System.in);

String str = scanner.nextLine();
Python 

str = input()

문자열을 뒤집는 데에는 다양한 방법을 떠올려볼 수 있다. 간단한 방식을 나열해보자.
  • 문자열의 맨 뒤에서부터 거꾸로 순회하며 출력해준다.
  • 문자열을 뒤집은 후 출력해준다. C++의 경우 <algorithm> 헤더에 std::reverse()가 있다.
  • 스택(Stack) 자료구조에 문자열의 문자를 차례대로 넣은 후, 다시 뽑으면서 출력해준다.

    • 이외에도 다양한 방법을 생각해 볼 수 있으며, 자신이 편한 방식으로 문제를 해결하면 되겠다.
