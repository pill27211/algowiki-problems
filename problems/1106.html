등차수열 출력하기

난이도 1 ⏱ 1.000s 🧠 512 MB
해 구성하기

문제

양의 정수 $n$이 주어진다. 길이 $n$의 등차수열을 하나 출력하여라. 단, 등차수열 $a_1, a_2, ... , a_n$은 모두 정수여야 하며, $|a_i| ≤ 10^9$를 만족해야 한다.

입력

첫째 줄에 양의 정수 $n$이 주어진다. $(1 ≤ n ≤ 1,000)$

출력

첫째 줄에 문제의 조건을 만족하는 길이 $n$의 등차수열을 공백으로 구분하여 출력한다. 정답이 여러가지인 경우 그 중 아무거나 출력해도 정답으로 인정된다.

예제

예제 입력
5
예제 출력
100000000 200000000 300000000 400000000 500000000

힌트

길이가 $5$인 등차수열은 출력 예시 $1$ 이외에도 무수히 많다.

연속한 두 항의 차가 일정한 수열을 등차수열이라고 한다. 길이 $n$의 등차수열을 떠올려보자. 그것이 바로 정답이다.
단, 모든 요소가 정수여야 하며 $|a_i| ≤ 10^9$여야 한다.
예를 들어 길이가 $5$인 등차수열을 나열해보자면 다음과 같을 것이다. 

1, 2, 3, 4, 5

5, 4, 3, 2, 1

3, 3, 3, 3, 3

1, 3, 5, 7, 9

...

이외에도 무수히 많은 등차수열이 존재한다.
