#1068

제곱수인가?

난이도 2 ⏱ 1.000s 🧠 512 MB
수학

문제

양의 정수 $n$이 주어진다. $n$은 제곱수인가?

입력

첫째 줄에 테스트 케이스의 개수 $T$가 주어진다. $(1 ≤ T ≤ 10,000)$

둘째 줄부터 $T$개의 줄에 걸쳐 $n$이 주어진다. $(1 ≤ n ≤ 10^9)$

출력

각 테스트 케이스마다 $n$이 제곱수라면 YES, 제곱수가 아니라면 NO를 출력한다.

예제

예제 입력
3

16

20

9
예제 출력
YES

NO

YES

힌트

제곱수란, 어떤 자연수의 제곱이 되는 수를 말한다.

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
$n$이 제곱수라는 것은, $(⌊\sqrt{n}⌋)^2 = n$ 가 된다는 것과 같다. 이를 이용해 $n$이 제곱수임을 판단하자.
