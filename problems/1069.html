#1069

수 정렬하기. 근데 이제 중복 제거를 곁들인

난이도 2 ⏱ 1.000s 🧠 512 MB
정렬

문제

모든 수가 양의 정수인 길이 $n$의 수열 $a_n$이 주어진다. 이 수열을 오름차순 정렬한 결과를 출력해보자. 단, 중복된 수가 있으면 안된다.

입력

첫째 줄에 수열 $a_n$의 길이 $n$이 주어진다. $(1 ≤ n ≤ 100,000)$

둘째 줄에 $a_1, a_2, ... , a_n$이 공백으로 구분되어 주어진다. $(1 ≤ a_i ≤ 10,000)$

출력

첫째 줄에 $a_n$을 오름차순 정렬한 결과를 공백으로 구분하여 출력한다. 단, 중복된 수가 있으면 안된다.

예제

예제 입력
6

1 1 2 2 3 3
예제 출력
1 2 3

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
$1 ≤ a_i ≤ 10,000$인 것을 관찰하여, 배열 하나를 정의하자. 

count[i] : 수열에서 i가 등장한다면 1, 등장하지 않는다면 0
$a_n$을 입력 받으면서 동시에 배열에 기록해준 후, 다음으로 문제를 해결할 수 있다. 

for i    ← 1 to 10,000

    if count[i] > 0

        print i
