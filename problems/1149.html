#1149

가장 긴 증가하는 부분 수열 (Small)

난이도 4 ⏱ 1.000s 🧠 512 MB
다이나믹 프로그래밍

문제

수열 $a_n$에 대해, 가장 긴 증가하는 부분 수열의 길이를 구하여라.

입력

첫째 줄에 수열의 길이 $n$이 주어진다. $(1 ≤ n ≤ 5,000)$

둘째 줄에 $a_1, a_2, ... , a_n$이 공백으로 구분되어 주어진다. $(1 ≤ a_i ≤ 10,000)$

출력

첫째 줄에 가장 긴 증가하는 부분 수열의 길이를 출력한다.

예제

예제 입력
5

1 4 2 3 5
예제 출력
4

💎 힌트 아이템

가장 긴 증가하는 부분 수열$(Longest$ $Increasing$ $Subsequence)$ 문제는 굉장히 유명한 문제로, $n$이 적당히 작을 땐 다이나믹 프로그래밍을 이용해 해결할 수 있다. 다음과 같이 정의해보자. 

dp[i] : a(i)를 마지막 요소로 갖는 가장 긴 증가하는 부분 수열의 길이
$dp[i]$를 계산하기 위해선 $1 ≤ j < i$ 이면서 $a_j < a_i$인 모든 $j$를 보면 된다. 

dp[1] = 1

for i        ← 2 to n

    for j    ← 1 to i-1

        if a[j] < a[i]

            dp[i] = max(dp[i], dp[j] + 1)
이 경우 $O(n^2)$의 시간복잡도로 문제를 해결할 수 있다.
