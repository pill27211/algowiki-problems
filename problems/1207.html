#1207

정답률 출력하기

난이도 1 ⏱ 1.000s 🧠 512 MB
수학 사칙연산

문제

하나의 문제를 $n$명의 사람이 풀었다. $i$번째 사람은 $t_i$번의 시도 끝에 문제를 풀었다고 한다.

$t_1, t_2, ... , t_n$이 주어졌을 때, 그 문제의 정답률을 출력해 보자. 정답률은 소수점 이하 넷째 자리 수에서 반올림해야 한다.

입력

첫째 줄에 문제를 푼 사람의 수를 의미하는 정수 $n$이 주어진다. $(1 ≤ n ≤ 1,000)$

둘째 줄부터 $n$개의 줄에 걸쳐 $t_1, t_2, ... , t_n$이 차례대로 주어진다. $(1 ≤ t_i ≤ 100)$

출력

첫째 줄에 정답률을 소수점 이하 넷째 자리 수에서 반올림하여 출력한다. 소수부는 반드시 셋째 자리까지 출력되어야 함을 유의한다.

예제

예제 입력
5

1

2

3

4

5
예제 출력
33.333%

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
$n$명의 사람이 총 $\sum\limits_{i=1}^n t_i$번의 시도로 문제를 풀었으므로, 정답률은 $\frac{ n }{ \sum\limits_{i=1}^n t_i } \times 100$ 로 계산된다.
실수 단위 출력이 이뤄져야 하므로 자료형에 유의하자. '%' 출력도 반드시 지켜야 한다. 언어별로 다음과 같이 간단히 반올림을 표현할 수 있다.
C 

printf("%.3lf", ans);
C++ 

cout << fixed << setprecision(3) << ans;
Java 

System.out.printf("%.3f", ans);
Python 

print("{:.3f}".format(ans))
