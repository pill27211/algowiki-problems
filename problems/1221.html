#1221

이항계수의 합 $1$

난이도 5 ⏱ 1.000s 🧠 512 MB
수학 조합론 분할 정복

문제

양의 정수 $n$이 주어질 때, 다음 값을 구하여라.

  • $\left(\begin{array}{c}n\\ 0\end{array}\right) + \left(\begin{array}{c}n\\ 1\end{array}\right) + \left(\begin{array}{c}n\\ 2\end{array}\right) + ... + \left(\begin{array}{c}n\\ n\end{array}\right)$

입력

첫째 줄에 양의 정수 $n$이 주어진다. $(1 ≤ n ≤ 10^{18})$

출력

첫째 줄에 문제의 답을 출력한다. 단, 수가 너무 커질 수 있으니 $10^9+7$로 나눈 나머지를 출력한다.

예제

예제 입력
2
예제 출력
4

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.

이항계수의 대표적인 성질 중 하나로, 다음이 성립한다. 이항 정리를 이용해 증명할 수 있다.

  • $\left(\begin{array}{c}n\\ 0\end{array}\right) + \left(\begin{array}{c}n\\ 1\end{array}\right) + \left(\begin{array}{c}n\\ 2\end{array}\right) + ... + \left(\begin{array}{c}n\\ n\end{array}\right) = 2^n$
단, $1 ≤ n ≤ 10^{18}$ 이므로 분할 정복을 이용해 $2^n$의 값을 $O(logn)$ 수준으로 구해주어야 제한 시간 내에 문제를 해결할 수 있다.
