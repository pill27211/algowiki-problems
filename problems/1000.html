힌트

본격적으로 알고리즘 공부를 시작하기 전에, 코드 작성에 다소 어려움이 있다면 힌트 아이템을 한번 사용해 보도록 하자.

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
C의 경우, 아래 코드를 바탕으로 원하는 문구를 출력할 수 있다. 
#include<stdio.h>



int main()

{

    printf("원하는 문구");

    return 0;

}
다음으로 C++ 
#include<iostream>



int main()

{

    std::cout << "원하는, 문구";

    return 0;

}
Java 
public class Main // 클래스 이름을 Main으로 해야 함을 유의하자.

{

    public static void main(String[] args)

    {

        System.out.println("원하는 문구");

    }

}
Python
