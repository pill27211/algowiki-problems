H 찍기

구현

문제

협성대학교의 첫 이니셜. 그것은 바로 'H'이다.
양의 정수 $N$이 주어질 때, 그 크기만큼의 'H'를 출력하자.

입력

첫째 줄에 양의 정수 $N$이 주어진다. $(1 ≤ N ≤ 50)$

출력

$N$만큼의 크기를 가진 'H'를 출력한다. 자세한 비율은 예제를 참고하자.

예제

예제 입력
1
예제 출력
* *

***

* *

$N$에 따른 가로, 세로의 길이는 모두 $N \times 2 + 1$이다.  $N \times 2 + 1$개의 행에 대해 중심행인 $N+1$번째 행에만 $N \times 2 + 1$개의 '*'이 있고 나머지 $N \times 2$개의 행은 전부 처음과 끝에만 '*'이 존재한다. 따라서, 다음의 흐름을 통해 문제를 해결할 수 있다. 

for i ← 1 to n * 2 + 1

    if i == n + 1

        ... ← 중심행 출력 (N * 2 + 1 개의 '*')

    else

        ... ← 나머지 행 출력 (처음과 끝에만 '*')

    ... ← 개행
