#1205

공백을 기준으로 문자열 자르기

난이도 1 ⏱ 1.000s 🧠 512 MB
구현 문자열 파싱

문제

알파벳 소문자와 대문자, 공백, 특수 문자(!?@#%.,)로만 이루어진 문자열 $S$가 주어진다. $S$를 공백을 기준으로 잘라보자. 공백이 연속해서 붙어 있는 경우는 하나로 봐야 한다.

입력

첫째 줄에 문자열 $S$가 주어진다. $S$는 공백으로 시작하거나 끝나지 않는다. $(1 ≤ |S| ≤ 1,000)$

출력

첫째 줄부터 한 줄에 하나씩 공백으로 분리된 $S$의 부분 문자열들을 출력한다.

예제

예제 입력
Hello! This is Algorithm Wiki.
예제 출력
Hello!

This

is

Algorithm

Wiki.

언어별로 공백을 기준으로 문자열을 자르는 방법을 소개해 보겠다.
C 

char str[] = "This is a test sentence";

char *token = strtok(str, " ");



while (token != NULL)

{

    printf("%s\n", token);

    token = strtok(NULL, " ");

}
C++ 

string str = "This is a test sentence";

stringstream ss(str);



for(string token; ss >> token;)

    cout << token << '\n';
Java 

String str = "This is a test sentence";

String[] words = str.split("\\s+");



for(String word : words)

    System.out.println(word);
Python 

str = "This is a test sentence";

words = str.split()



for token in words:

    print(token)
