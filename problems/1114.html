#1114

$a_i + a_j = k$ $(2)$

난이도 3 ⏱ 1.000s 🧠 512 MB
정렬 투 포인터

문제

길이 $n$의 수열 $a_1, a_2, ... , a_n$과 정수 $k$가 주어진다. $1 ≤ i < j ≤ n$인 $i, j$에 대해 $a_i$ + $a_j$ = $k$를 만족하는 $(i, j)$쌍의 개수를 구하여라.

입력

첫째 줄에 수열의 길이 $n$과 정수 $k$가 공백으로 구분되어 주어진다. $(1 ≤ n ≤ 10^5; 1 ≤ k ≤ 2 \times 10^6)$

둘째 줄에 $a_1, a_2, ... , a_n$이 공백으로 구분되어 주어진다. $(1 ≤ a_i ≤ 10^6)$

입력으로 주어지는 모든 수는 정수이며, $a_i$는 유일하다.

출력

첫째 줄에 문제의 정답을 출력한다.

예제

예제 입력
5 6

1 2 3 4 5
예제 출력
2
