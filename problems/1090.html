#1090

6의 배수

난이도 3 ⏱ 1.000s 🧠 512 MB
구현 문자열 수학

문제

양의 정수 $n$이 주어진다. $n$은 $6$의 배수인가?

입력

첫째 줄에 양의 정수 $n$이 주어진다. $(6 ≤ n ≤ 10^{6666})$

출력

첫째 줄에 $n$이 $6$의 배수라면 YES, 배수가 아니라면 NO를 출력한다.

예제

예제 입력
66
예제 출력
YES

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.

$6$의 배수는 곧 $2$와 $3$의 공배수로, $2$와 $3$의 배수임을 판정하면 된다.

  • $2$의 배수 : 일의 자리 수가 짝수여야 한다.
  • $3$의 배수 : 각 자리 수의 합이 3의 배수여야 한다.
