#1241

$3$차원 더하기

난이도 7 ⏱ 1.000s 🧠 512 MB
누적 합 imos법 쿼리형 문제

문제

$N \times M$개의 칸으로 이루어진 직사각형 $H$개가 아래에서 위로 균일하게 쌓여있다. 맨 아래에 있는 직사각형의 높이는 $1$이고 맨 위에 있는 직사각형의 높이는 $H$가 된다. 또한 한 직사각형을 놓고 볼 때 맨 왼쪽 위의 좌표는 $(1, 1)$, 맨 오른쪽 아래 좌표는 $(N, M)$이 된다.

따라서 각 칸은 $(1, 1, 1)$ 부터 $(H, N, M)$까지의 고유한 좌표를 갖는다. 최초 각 칸은 $0$의 값을 갖는다.

다음 쿼리를 수행하는 프로그램을 작성하자.

  • $h_1$ $h_2$ $y_1$ $y_2$ $x_1$ $x_2$ $k$ : 아래 조건을 만족하는 모든 $(h, y, x)$의 값에 $k$를 더한다.
    • $h_1 ≤ h ≤ h_2$
    • $y_1 ≤ y ≤ y_2$
    • $x_1 ≤ x ≤ x_2$

입력

첫째 줄에 $N, M, H$와 쿼리의 개수 $Q$가 공백으로 구분되어 주어진다. $(1 ≤ N, M, H ≤ 50; 1 ≤ Q ≤ 2 \times 10^5)$

둘째 줄부터 $Q$개의 줄에 걸쳐 $h_1$ $h_2$ $y_1$ $y_2$ $x_1$ $x_2$ $k$가 공백으로 구분되어 주어진다.

  • $1 ≤ h_1 ≤ h_2 ≤ H$
  • $1 ≤ y_1 ≤ y_2 ≤ N$
  • $1 ≤ x_1 ≤ x_2 ≤ M$
  • $1 ≤ k ≤ 1,000$
입력으로 주어지는 모든 수는 정수이다.

출력

$Q$개의 쿼리에 대한 처리가 끝난 후, $H \times (N + 1)$개의 줄에 걸쳐 최종 직사각형들의 모습을 출력한다. 직사각형들은 아래에서 위로 쌓여있기 때문에, 높이가 $H, H-1, ... , 1$인 직사각형의 모습을 차례대로 출력해야 한다.

각 직사각형은 다음의 출력 형식을 따라야 한다.

  • $N+1$개의 줄에 걸쳐 출력된다.
    • $1 ≤ i ≤ N$인 $i$번째 줄에는 해당 직사각형의 $(i, 1), (i, 2), ... , (i, M)$을 공백으로 구분해 출력한다.
    • $N+1$번째 줄은 개행('\n')해야 한다.

예제

예제 입력
4 3 3 3

1 2 2 4 1 2 1

2 3 2 3 2 3 1

1 3 1 4 1 3 2

2 2 2
