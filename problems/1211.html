#1211

피라미드 탑 쌓기

난이도 4 ⏱ 1.000s 🧠 512 MB
수학 이분 탐색 쿼리형 문제

문제

크기가 동일한 $25$개의 블록으로 다음과 같은 $5$층 피라미드 탑을 쌓을 수 있다.

만약 블록의 개수가 $24$개였다면 최대 $4$층 높이의 피라미드를 쌓을 수 있고 $8$개의 블록이 남았을 것이다.

이를 바탕으로 아래와 같은 쿼리 $Q$개를 처리하는 프로그램을 작성해보자.

  • $N$ : $N$개의 블록을 가지고 쌓을 수 있는 최대 피라미드 높이와 쌓은 후 남게 되는 블록의 수를 공백으로 구분하여 출력한다.

입력

첫째 줄에 쿼리의 개수 $Q$가 주어진다. $(1 ≤ Q ≤ 100,000)$

둘째 줄부터 $Q$개의 줄에 걸쳐 블록의 수를 의미하는 정수 $N$이 주어진다. $(1 ≤ N ≤ 10^{18})$

출력

쿼리가 주어질 때마다 그에 맞는 정답을 차례대로 출력한다.

예제

예제 입력
3

4

24

25
예제 출력
2 0

4 8

5 0

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
블록의 개수가 적당히 작았다면, $N$에서 $1, 3, 5, ...$를 차례대로 빼내보며 나이브하게 답을 구해도 충분했을 것이다.
그러나 본 문제는 $1 ≤ n ≤ 10^{18}$인 $N$에 대한 답을 $10^5$번까지 구할 수 있어야 하기 때문에 나이브한 방식을 적용하기엔 다소 무리가 있다.

수열 $a$에 대해 $a_i$를 "$i$층 높이의 피라미드 탑을 쌓기 위해 필요한 블록의 개수"로 정의하면 $a$는 다음과 같을 것이다.
  • $1^2, 2^2, 3^2, ... , ({10^9})^2$

    • 우리가 해결해야 할 쿼리의 내용은 결국 수열 $a$에서 $N$의 위치를 찾아내야 하는 것으로 바라볼 수 있고, $a$는 단조 증가하므로 이분 탐색을 이용해 빠르게 찾아낼 수 있다. 시간복잡도는 $O(QlogN)$이 되겠다.

    구현은 다음을 참고하자. 
    
maxH = 0, remain = 0          ← 최대 피라미드 높이, 남게 되는 블록의 수

left = 1, right = 1e9         ← 존재할 수 있는 층은 1 ~ 1e9

for left <= right

    mid = (left + right) / 2

    if n >= mid * mid         ← 주어진 블록(N)을 이용해 mid층의 피라미드를 쌓을 수 있는가?

        maxH = mid

        remain = n - mid * mid

        left = mid + 1

    else

        right = mid - 1
