문제

알파벳 소문자로만 이루어진 두 문자열 $S$와 $T$가 주어진다. $S$에 아래 연산을 자유롭게 수행하되, 최소한으로 수행하여 $S$를 $T$로 만들어 보아라.

  • $S$의 특정 위치에 문자 하나를 추가한다.
  • $S$의 특정 위치의 문자 하나를 제거한다.
  • $S$의 특정 위치의 문자 하나를 다른 문자로 변경한다.

입력

첫째 줄에 문자열 $S$, 둘째 줄에 문자열 $T$가 주어진다. $(1 ≤ |S|, |T| ≤ 1,000)$

출력

첫째 줄에 $S$를 $T$로 만들기 위해 수행해야 하는 최소한의 연산 횟수를 출력한다.

예제

예제 입력
algowiki

algorithm
예제 출력
4
