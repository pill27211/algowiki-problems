#1249

피보나치 수 4

난이도 8 ⏱ 1.000s 🧠 512 MB
수학 정수론 다이나믹 프로그래밍 배낭 문제

문제

피보나치 수 $F_n$은 다음으로 정의되는 수열이다.

$0$번째 항 $F_0 = 0$을 시작으로 초항을 나열해보면 다음과 같을 것이다.

  • $0, 1, 1, 2, 3, 5, 8, 13, ...$

정수 $n$이 주어질 때, 다음 기준에 의거하여 $n$을 피보나치 수의 합으로 표현하는 방법의 수를 구하는 프로그램을 작성해 보자.

  • 위에서 정의한 피보나치 수열에서 $F_2$ 이상의 수부터 사용할 수 있다.
  • 사용한 수가 같고 순서가 다른 경우는 같은 경우로 친다. 즉, $\{1+3\}$과 $\{3+1\}$는 두 가지가 아니라 한 가지로 친다.
  • 같은 피보나치 수를 중복해서 사용할 수 있다.
예를 들어 $4$는 $\{1 + 1 + 1 +1\}$, $\{1 + 1 + 2\}$, $\{2 + 2\}$, $\{3+1\}$로 총 네 가지가 있다.

입력

첫쨰 줄에 테스트 케이스의 수를 의미하는 정수 $T$가 주어진다. $(1 ≤ T ≤ 10^5)$

둘째 줄부터 $T$개의 줄에 걸쳐 정수 $n$이 주어진다. $(1 ≤ n ≤ 3 \times 10^6)$

출력

$T$개의 줄에 걸쳐 $n$이 주어질 때마다 그에 맞는 정답을 한 줄에 하나씩 차례대로 출력한다. 단, 수가 너무 커질 수 있으니 $10^9+7$로 나눈 나머지를 출력한다.

예제

예제 입력
3

4

6

10
예제 출력
4

8

22
