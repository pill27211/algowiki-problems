#1245

올바른 괄호 문자열의 개수의 합

난이도 7 ⏱ 1.000s 🧠 512 MB
수학 다이나믹 프로그래밍 조합론

문제

'('와 ')'로만 이루어진 문자열이 다음을 만족한다면 '올바른 괄호 문자열'이라고 할 수 있다.

  • "()"는 올바른 괄호 문자열이다.
  • A가 올바른 괄호 문자열이라면, "(A)"도 올바른 괄호 문자열이다.
  • A와 B가 올바른 괄호 문자열이라면, 둘을 이어붙인 AB도 올바른 괄호 문자열이다.
위 정의에 따라, 수열 $P = P_1, P_2, ... , P_n$을 다음과 같이 정의할 수 있다.
  • $P_i$ : 길이가 $i$인 서로 다른 올바른 괄호 문자열의 개수
정수 $n$이 주어질 때, $\sum\limits_{i=1}^n P_i$의 값을 구하는 프로그램을 작성하여라.

입력

첫째 줄에 수열의 길이를 의미하는 정수 $n$이 주어진다. $(1 ≤ n ≤ 3,000)$

출력

첫째 줄에 $\sum\limits_{i=1}^n P_i$의 값을 출력한다. 단, 수가 너무 커질 수 있으니 $10^9 + 7$로 나눈 나머지를 출력한다.

예제

예제 입력
4
예제 출력
3

힌트

길이가 $4$ 이하인 서로 다른 올바른 괄호 문자열은 "()", "()()", "(())"로 총 세 가지가 있다.
