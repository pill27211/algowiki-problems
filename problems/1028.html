#1028

소수 판정 (Large)

난이도 4 ⏱ 2.000s 🧠 128 MB
수학 정수론 소수 판정 에라토스테네스의 체

문제

양의 정수 $x$가 주어진다. $x$가 소수인지 판정해보자.

입력

첫째 줄에 테스트 케이스의 수를 의미하는 $T$가 주어진다. $(1 ≤ T ≤ 10^5)$

둘째 줄부터 $T$개의 줄에 걸쳐 $x$가 주어진다. $(1 ≤ x ≤ 10^6)$

출력

각 테스트 케이스마다 $x$가 소수라면 YES, 소수가 아니라면 NO를 출력한다.

예제

예제 입력
4

2

4

7

10
예제 출력
YES

NO

YES

NO

힌트

문제 해결에 어려움이 있다면 소수 판정 위키를 참고하자.
