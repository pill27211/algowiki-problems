#1001

사칙연산

난이도 1 ⏱ 1.000s 🧠 128 MB
구현 수학 사칙연산

문제

간단한 사칙연산을 수행하는 프로그램을 작성해보자.
사칙연산이란, 덧셈$(+)$, 뺄셈$(-)$, 곱셈$(\times)$, 나눗셈$(/)$의 네 가지 이항연산을 묶어 부르는 말이다.

입력

첫째 줄에 정수 $A, B$가 공백으로 구분되어 주어진다.$(-40,000 ≤ A, B ≤ 40,000; B ≤ A)$
$A/B$의 결과가 항상 정수임이 보장된다.

출력

첫째 줄에 $A+B$, $A-B$, $A \times B$, $A/B$의 결과를 공백으로 구분하여 출력한다.

예제

예제 입력
10 5
예제 출력
15 5 50 2

힌트

코드는 일반적으로 작성되어야 합니다. 즉, 예시 $1$뿐만 아니라 '$10$ $2$'나 '$15$ $5$'처럼 문제에서 정의한 입력 조건을 만족하는 어떠한 입력에 대해서도 올바른 출력이 이뤄질 수 있어야 합니다.

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
두 정수가 공백으로 구분되어 주어질 경우, C / C++은 다음과 같이 공백을 따로 생각하지 않아도 된다. 

int a, b;

// C

scanf("%d %d", &a, &b);

// C++

cin >> a >> b;
Java나 Python의 경우 공백을 비롯해 입력 형식에 좀 더 신경 써주어야 한다.
Java 

// Scanner를 이용한 방법

Scanner scanner = new Scanner(System.in);

int a = scanner.nextInt();

int b = scanner.nextInt();



// BufferedReader를 이용한 방법

BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

String[] token = br.readLine().split(" ");

int a = Integer.parseInt(token[0]);

int b = Integer.parseInt(token[1]);
Python 

// 가장 많이 쓰이는 방식

a, b = map(int, input().split())
이제 입력 받은 두 수 a, b에 대해 사칙연산의 결과를 차례대로 출력하자. 나눗셈의 결과가 정수임이 보장되므로, 실수 자료형을 기용할 필요는 없다. 출력할 때 역시 공백으로 구분해야 함을 유의해야 한다.
