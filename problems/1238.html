#1238

합, 차, 곱

난이도 5 ⏱ 1.000s 🧠 512 MB
수학 정렬

문제

모든 요소가 정수인 길이 $n$의 수열 $a_1, a_2, ... , a_n$이 주어진다. 다음 값을 구하여라.

  • $\sum\limits_{i=1}^n \sum\limits_{j=1}^n (|a_i+a_j| + |a_i-a_j| + |a_i \times a_j|)$

입력

첫째 줄에 수열의 길이를 의미하는 정수 $n$이 주어진다. $(1 ≤ n ≤ 200,000)$

둘째 줄에 $a_1, a_2, ... , a_n$이 공백으로 구분되어 주어진다. $(1 ≤ a_i ≤ 10^9)$

출력

첫째 줄에 $\sum\limits_{i=1}^n \sum\limits_{j=1}^n (|a_i+a_j| + |a_i-a_j| + |a_i \times a_j|)$의 값을 출력한다. 단, 수가 너무 커질 수 있으니 $10^9+7$로 나눈 나머지를 출력한다.

예제

예제 입력
5

1 2 3 4 5
예제 출력
415
