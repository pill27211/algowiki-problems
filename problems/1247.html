#1247

열매 수확하기

문제

커다란 나무 속 $N$개의 가지가 트리 구조로 연결되어 있다. 각 가지는 $1, 2, ... , N$의 번호를 갖으며, $i$번 가지에 $W_i$ 이상의 물이 전달되면 $i$번 가지에서 열매를 수확할 수 있다.

각 가지에서는 최대 하나의 열매만을 수확할 수 있기 때문에, 나무에서 얻을 수 있는 열매의 최대 개수는 $N$개이다.

이제 총 $Q$번의 걸쳐 이 나무에 물을 주려고 한다. 물을 주는 형태는 다음을 따른다.

  • $u$ $v$ : $u$번 가지부터 $v$번 가지에 이르는 최단 경로 위 존재하는 모든 가지에 $1$만큼 물을 준다.
$Q$번에 걸쳐 나무에 물을 준 후 최종적으로 수확할 수 있는 열매의 개수를 구해주는 프로그램을 작성해 보도록 하자.

입력

첫째 줄에 가지의 개수를 의미하는 정수 $N$이 주어진다. $(1 ≤ N ≤ 100,000)$

둘째 줄에 가지별 열매를 수확할 수 있는 기준 $W_1, W_2, ... , W_N$이 공백으로 구분되어 주어진다. $(1 ≤ W_i ≤ 10,000)$

셋째 줄부터 $N-1$개의 줄에 걸쳐 $u, v$가 공백으로 구분되어 주어진다. 이는 $u$번 가지와 $v$번 가지가 직접적으로 연결되어 있다는 뜻이다. $(1 ≤ u, v ≤ N; u ≠ v)$

$N+2$번째 줄에는 나무에 물을 주는 횟수 $Q$가 주어진다. $(1 ≤ Q ≤ 100,000)$

다음으로 $Q$개의 줄에 걸쳐 $u, v$가 공백으로 구분되어 주어진다. $(1 ≤ u, v ≤ N)$

출력

첫째 줄에 $Q$번에 걸쳐 나무에 물을 준 후 최종적으로 수확할 수 있는 열매의 개수를 출력한다.

예제

예제 입력
