#1233

수열 색칠하기 1

난이도 4 ⏱ 1.000s 🧠 512 MB
다이나믹 프로그래밍

문제

$1, 2, ... , n$의 번호가 고유하게 매겨진 길이 $n$의 수열이 있다. 아래 기준을 만족하면서 수열을 색칠하려 할 때, 발생하는 비용의 최솟값을 구하여라.

  • $i$번 요소를 빨강색, 초록색, 파랑색으로 칠할 때 각각 $R_i, G_i, B_i$의 비용이 발생한다.
  • 인접한 요소는 서로 다른 색으로 칠해져야 한다. 즉, $i$번 요소와 $i+1$번 요소를 같은 색으로 연달아 칠할 수 없다.

입력

첫째 줄에 수열의 길이를 의미하는 정수 $n$이 주어진다. $(1 ≤ n ≤ 10,000)$

둘째 줄에 $R_1, R_2, ... , R_n$이 공백으로 구분되어 주어진다. $(1 ≤ R_i ≤ 1,000)$

셋째 줄에 $G_1, G_2, ... , G_n$이 공백으로 구분되어 주어진다. $(1 ≤ G_i ≤ 1,000)$

넷째 줄에 $B_1, B_2, ... , B_n$이 공백으로 구분되어 주어진다. $(1 ≤ B_i ≤ 1,000)$

출력

첫째 줄에 조건을 만족하면서 수열을 색칠하는 비용의 최솟값을 출력한다.

예제

예제 입력
5

1 3 1 3 2

4 2 2 1 1

2 3 2 3 2
예제 출력
7

다이나믹 프로그래밍을 이용해 해결할 수 있다. 다음과 같이 정의하자. 

dp[i][j] : 1, 2, ... , i를 색칠하는 최소 비용. 단, i번 요소의 색은 j

j = 0 → 빨강색

j = 1 → 초록색

j = 2 → 파랑색
그럼 문제의 조건에 따라 다음의 점화식이 성립한다. 

dp[i][0] = min(dp[i - 1][1], dp[i - 1][2]) + R[i];

dp[i][1] = min(dp[i - 1][0], dp[i - 1][2]) + G[i];

dp[i][2] = min(dp[i - 1][0], dp[i - 1][1]) + B[i];
최종적으로 답은 다음으로 정해진다. 

min(dp[n][0], dp[n][1], dp[n][2])
