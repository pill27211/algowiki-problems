#1076

트리랑 친해지기 1

난이도 4 ⏱ 1.000s 🧠 512 MB
그래프 이론 그래프 탐색 깊이 우선 탐색 너비 우선 탐색 트리

문제

$N$개의 정점으로 구성된 트리가 주어진다. 각 정점에는 $1, 2, ... , N$의 번호가 할당된다.

$1$번 정점이 루트이자 $1$의 깊이를 가질 때, 정점별 깊이를 모두 구해보자.

입력

첫째 줄에 정점의 개수 $N$이 주어진다. $(1 ≤ N ≤ 100,000)$

둘째 줄부터 $N-1$개의 줄에 걸쳐 간선 하나가 잇는 두 정점의 번호 $u, v$가 공백으로 구분되어 주어진다. $(1 ≤ u, v ≤ N)$

출력

첫째 줄에 $1, 2, ... , N$번 정점의 깊이를 공백으로 구분하여 출력한다.

예제

예제 입력
6

1 2

1 3

2 4

2 5

3 6
예제 출력
1 2 2 3 3 3

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.
한 번의 $DFS($혹은 $BFS)$로 문제를 해결할 수 있다. 다음을 참고하자. 

dfs(now, prev)    ← 현재 정점, 이전 정점

{

    depth[now] = depth[prev] + 1

    for i    ← now와 연결된 정점들을 순회

        if i == prev

            continue

        dfs(i, now)

}
