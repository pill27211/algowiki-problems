#1174

Inversion Counting (Large)

난이도 9 ⏱ 1.000s 🧠 512 MB
자료 구조 정렬 세그먼트 트리 분할 정복

문제

유명한 문제 중 하나인 Inversion Counting 문제를 풀어보자. 모든 원소가 고유한 수열  $a_1, a_2, ... , a_n$에 대해 아래의 값을 구하면 된다.

  • $1 ≤ i < j ≤ n$인 순서쌍 $(i, j)$에 대해 $a_i > a_j$를 만족하는 쌍의 개수

입력

첫째 줄에 수열의 길이 $n$이 주어진다. $(2 ≤ n ≤ 200,000)$

둘째 줄에 $a_1, a_2, ... , a_n$이 공백으로 구분되어 주어진다.$(1 ≤ a_i ≤ n)$

출력

첫째 줄에 문제의 정답을 출력한다.

예제

예제 입력
7

1 3 7 5 4 2 6
예제 출력
8

힌트

$(i, j) = (2, 6), (3, 4), (3, 5), (3, 6), (3, 7), (4, 5), (4, 6), (5, 6)$ 로 총 $8$가지가 있다.

💎 힌트 아이템

AlgoWiki의 인벤토리·아이템 시스템으로 잠금 해제되던 프리미엄 힌트입니다.

$1 ≤ a_i ≤ n$인 순열이므로 다음의 시뮬레이션을 통해 답을 계산할 수 있다.

  1. 최초 $1, 2, ... , n$에 부여된 가중치는 $0$이며, $i = 1$로 시작한다.
  2. $a_i < j ≤ n$ 인 모든 $j$의 가중치를 답에 누적한다.
  3. $a_i$에 $1$의 가중치를 부여하고, $i$를 $1$ 증가 시킨다.
  4. $i < n$이라면 $2$로 돌아간다.
위를 만약 나이브하게 수행하면 $O(n^2)$의 시간 복잡도를 갖게 되어 제한 시간 내에 문제를 해결할 수 없게 된다. 구간의 변화를 세그먼트 트리로 관리해 보자. 그럼 $2, 3$ 단계를 $O(logn)$에 처리할 수 있으므로, 문제를 $O(nlogn)$에 해결할 수 있게 된다.

※ 병합 정렬의 개념을 이용한 분할 정복으로도 $O(nlogn)$에 해결할 수 있다.
