## AlgoWiki?

협성대학교 소프트웨어학과 졸업작품으로 팀과 함께 개발·운영한 알고리즘 온라인 저지입니다.
오픈소스 [hustoj](https://github.com/zhblue/hustoj)를 기반으로, 저는 백엔드·인프라와 함께
채점 외적인 **게임화 레이어(퀘스트 · 상점/인벤토리 · 복권 · 칭호 · 아이템)의 백엔드**를 직접 구현했고, **플랫폼에 들어가는 문제 전량을 직접 출제**했습니다. 이 레포는 그중 문제 자산만 따로 모은 것입니다.

## 이 아카이브

| | |
|---|---|
| **217** | 수록 문제 |
| **67** | 알고리즘 분류 |

**백준 온라인 저지(BOJ)** 에서 많은 영감을 받아, 제 PS(문제풀이) 경험을 바탕으로 문제의 명세·예제·힌트를 만들었습니다.
게임화 시스템의 **'힌트 아이템'** 으로 잠금 해제되던 프리미엄 힌트도 함께 담겨 있습니다.

## 메모

- 원래는 문제마다 **채점용 테스트 데이터 제너레이터**도 매번 직접 작성했습니다. 제너레이터 자체는
  그때그때 쓰고 지워 남아있지 않지만, 당시 생성한 **문제별 채점 데이터는 보관하고 있으니 필요하시면 문의해 주세요.**
- 이 레포는 **문제 아카이브**이며 저지 시스템 자체를 재현하지 않습니다.
  실제 운영 DB(사용자 계정·제출 기록 등)는 개인정보 보호를 위해 **포함하지 않았습니다.**

## 구성 · 빌드

운영 DB에 저장돼 있던 문제들을 추출해, 프레임워크 없이 **정적 HTML** 로 렌더했습니다.

- 수식은 **MathJax** 로 렌더 (문제 대부분이 LaTeX 표기를 사용합니다)
- 목록 페이지는 **클라이언트 사이드 검색 + 분류/난이도 필터**
- `index.html` (목록) · `problems/<번호>.html` (문제별 명세) · `assets/` (스타일·스크립트·이미지)
